This page lists the complete technical specifications for MK.IO Beam reception workflows, covering compressed input formats, satellite hardware, video and audio decoding, ancillary data, transcoding, compressed and uncompressed outputs, content security, ad insertion, and monitoring options.

## Compressed Input

### IP Input

- **Type:** IP (IGMPv3-based redundancy and dual multicast redundancy)
- **Protocols:** MPEG Transport Stream (SPTS, MPTS), RTP / UDP, RTMP, SMPTE ST 2022-7
- **Bitrate:** Constant Bitrate (CBR)
- **Error Correction:** ProMPEG FEC

### Reliable Transport

- **Input:** IP-based
- **Protocols:** SRT, RIST, and Zixi

**SRT and RIST input:**
- Carriage of UDP or RTP streams over the SRT protocol
- SRT listener or caller mode
- RIST sender mode
- RIST listener mode

**Zixi input:**
- Zixi sender
- Zixi feeder or Zixi Receiver mode

### Satellite Input

- **Standards:** DVB-S, DVB-S2, DVB-S2X
- **Hardware requirements:** Requires one or more of the following cards

<Accordion title="2-Port Satellite Demodulator Option Card with 3G-SDI/ASI Output (Dektec DTA-2127)">
  MediaKind marketing code: **MKP/HWO/DEMODSDI** (Dektec DTA-2127 DVB-S2X Quad Receiver with 3G-SDI/ASI Output)

  The Dektec DTA-2127 option card has 2 × RF input ports. MK.IO Beam currently supports configuring one tuner/demodulator per RF input.

  - **Frequency range:** L-band (950–2150 MHz)
  - **Standards:** DVB-S, DVB-S2, DVB-S2X
  - **Modulation schemes:** QPSK, 8PSK, 16APSK, 32APSK
  - **Connector:** 2 × F-type 75 ohm — each connector allows 1× independent tuner/demodulator powered by a single LNB control
  - Long FEC Frame only
</Accordion>

<Accordion title="4-Port Satellite Demodulator Option Card (Digital Devices SX8)">
  MediaKind marketing code: **MKP/HWO/PCI/SAT/DEMOD** (Digital Devices SX8 Satellite Demod)

  The Digital Devices SX8 is only available as a full-height PCIe card and is therefore limited to servers such as the C-series.

  - **Frequency range:** L-band (950–2150 MHz)
  - **Standards:** DVB-S, DVB-S2, DVB-S2X
  - **Modulation schemes:** QPSK, 8PSK, 16APSK, 32APSK, 64APSK
  - **Connector:** 4 × F-type 75 ohm — each connector allows 2× independent tuners/demodulators that share a single LNB control

  Mixing both types of satellite demodulator cards within the same server is not supported.
</Accordion>

### ASI Input

- **Standards:** DVB-ASI
- **Hardware requirements:** Requires one or more of the following cards

<Accordion title="4-Port ASI/SDI Option Card (Dektec DTA-2174B)">
  MediaKind marketing code: **MKP/HWO/PCI/SDI/DTA** (Dektec 2174B SDI/ASI)

  - **Port configurations:** 4× ASI input/output
  - **Connector:** micro BNC 75 ohms
</Accordion>

<Accordion title="8-Port ASI/SDI Option Card (Dektec DTA-2178)">
  MediaKind marketing code: **MKP/HWO/PCI/SDI/8** (Dektec 2178 SDI/ASI)

  - **Port configurations:** 8× ASI input/output
  - **Connector:** micro BNC 75 ohms
</Accordion>

### Input Redundancy

- **Dual source redundancy:** Active Passive (one-hit); Active Active (one-hit); Active Active (switch on failure)
  - Supported across input types, e.g., Primary satellite input, Secondary (Backup) IP input
- **IP redundancy protocols:** SMPTE ST 2022-7 seamless protection switching

## Video Decoding

- **Video codecs:** MPEG-2, H.264, HEVC, JPEG-XS
- **Supported resolutions:** 480i, 576i, 720p, 1080i, 1080p, 2160p
- **Chroma:** 4:2:0 and 4:2:2
- **Bit depth:** 8-bit and 10-bit (codec-dependent)

### Full Video Width Scaling

Horizontally subsampled video is automatically rescaled to full frame width. Supported for all video codecs listed above.

| Input Resolution | Output Resolution | Expected Sample Aspect Ratio |
| :-- | :-- | :-- |
| 1440 × 1080 | 1920 × 1080 | 4:3 |
| 1280 × 1080 | 1920 × 1080 | 3:2 |
| 960 × 1080 | 1920 × 1080 | 2:1 |
| 960 × 720 | 1280 × 720 | 4:3 |
| 640 × 720 | 1280 × 720 | 2:1 |

### Video Down-Conversions

- 2160p > 1080p, 1080i, 720p
- 1080p > 1080i, 720p
- 1080i > 720p

### Video Up-Conversions

- 1080i > 1080p
- 720p > 1080i

### HDR to SDR Conversions

- **Supported HDR inputs:** PQ10 (HDR10), HLG10
- **Output:** SDR BT.709 with tone mapping

## Audio Decoding

- **Audio codecs:** MP1L2, AAC, AAC 5.1, HE-AAC v1 & v2, HE-AAC 5.1, Dolby Digital (AC-3) 2.0 & 5.1, Dolby Digital Plus (E-AC-3) 2.0 & 5.1, MPEG-H
- **Passthrough:** Linear PCM, Dolby E, Dolby ED2, Dolby Digital (AC-3), Dolby Digital Plus (E-AC-3)
- **Audio sampling rate:** 48 kHz
- **Audio channels:** Up to 8 stereo pairs per service
- **Phase Aligned Audio (PAA):** Supported

### Video Encoding

- **Codecs:** MPEG-2, MPEG-4 AVC (H.264), HEVC (H.265)
- **Chroma:** 4:2:0
- **Conversions:**
  - HD to HD or SD
  - SD to SD

### Audio Encoding

- **Audio codecs:** MPEG-1 Layer-II, AAC, HE-AAC, HE-AAC v2, Dolby Digital® 2.0/5.1, Dolby Digital Plus® 2.0/5.1, Dolby AC-3
- **Audio channels:** Up to 8 stereo pairs per service
- **Passthrough:** Dolby E®, Dolby Digital®, Dolby Digital Plus®, Linear PCM (as SMPTE 302)
- **Data rate:** From 4.75 kbps to 320 kbps (from 64 to 1024 kbps for DD+)

## Multiplexing

### Inputs and Outputs

- IP (UDP or RTP) input and output of MPEG Transport Streams
- RTP re-ordering
- IGMP V3 redundancy
- Input bitrate monitoring and CC error detection
- SMPTE 2022-1 FEC on input and output

### Processing

- PID filtering and PID remapping by re-multiplexing input programs
- Real-time PSI regeneration

## Content Security

### Decryption

- **Conditional Access (CA):** BISS1, BISS2, BISS-CA, Director 6, DVB-CI

<Accordion title="BISS1 and BISS2">
  **BISS version 1 (BISS1):**
  - Modes: Mode 1 and Mode E
  - Key length: 48-bit
  - Standards: DVB-CSA

  **BISS version 2 (BISS2):**
  - Modes: Mode 1, Mode E, and BISS-CA
  - Key length: 128-bit
  - Standards: DVB-CISSA
</Accordion>

<Accordion title="BISS-CA">
  A Trusted Platform Module (TPM) must be installed on the server.

  - Key length: 128-bit
  - Standards: DVB-CISSA
  - Features: Entitlement management, self-generated key pairs, injected key pairs
</Accordion>

<Accordion title="Director 6 CA">
  A Trusted Platform Module (TPM) must be installed on the server.

  - Key length: 128-bit
  - Features: Entitlement management, Over Air Control (OAC)
</Accordion>

<Accordion title="Dual Common Interface (CI) Option Card (Digital Devices Octopus Duo CI)">
  MediaKind marketing code: **MKP/HWO/PCI/CI/DUAL**

  The Digital Devices Octopus Duo CI is only available as a full-height PCIe card and is limited to servers such as the C-series.

  - DVB-CI compliant
  - 2× CI slots for two independent CAMs per option card
  - Capable of processing transport streams up to 96 Mbps per CAM (actual bitrate may be limited by the CAM)
  - All major CAMs supported
  - Multiple Dual Common Interface option cards supported

  Some CA descramblers require a Trusted Platform Module (TPM) to be installed on the server.
</Accordion>

## Ad Insertion

- **Ingest format:** MPEG-TS over IP (SPTS) with a video buffer of 1 second minimum; assets pre-encoded and stored locally
- **Scheduling control:** Triggered via:
  - **Signal-based:** Based on submitted SCTE-35 signal (with matching criteria)
  - **Signal-based / fallback to time:** SCTE-35 expected but absent; falls back to out-of-band operations triggering
- **Asset management:**
  - Storage of up to 90 minutes of assets in the unit
  - Assets and schedules fetched automatically from a central asset server
  - Automatic housekeeping of the asset store

- **Remote control:** Via the MediaKind MK.IO portal
- **Direct control and status monitoring:** Via web browser user interface and REST API
- **Standard protocols:** SNMP, NTP, IGMP

**High Availability (HA) Controller:**

- Automated (standalone) 1+1 output synchronization with PTS alignment (either SDI or ST 2110 inputs)
