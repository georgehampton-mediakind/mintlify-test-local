This page lists the release notes for MK.IO Beam software, covering new features, improvements, and hardware support changes across versions.

## MK.IO Beam 1.14.0.1

**4th September 2026**

### New Features

- Support for reception workflows using the Essentials UI
- Automatic CPIX key rotation — see [Key Rotation](/beam/headends/packager
- MK.IO Beam ISO support for servers with hardware RAID'd disks — see [RAID and FakeRAID configuration](/beam/system-admin/iso-installation)

---

## MK.IO Beam 1.13.0.7

**21st August 2026**

### New Features

- Addition of an RT (reliable transport) failover group for high availability distributed deployments
- Manual CPIX key rotation

---

## MK.IO Beam 1.12.0.7

**17th July 2026**

### New Features

- Essentials UI for new customers only
- Ability to change the audio line-up on a Receiver service without interruption in the video output (SDI output only)
- Null Packet Removal from Multiplexer transport stream output bitrate — allows users to remove NULL packets (PID 0x1FFF) from the MPEG transport stream output

---

## MK.IO Beam 1.11.0.4

**2nd July 2026**

### New Features

- SMPTE ST 2110 end-to-end latency reduced to match SDI performance
- Packager — CPIX key and credential support
- Support for multiple UHD ST2110 outputs on a single Mellanox card

---

## MK.IO Beam 1.10.0.2

**29th May 2026**

### New Features

- Support for 100G ST 2110 Network Card in MK.IO Beam
- Support for ConnectX-6 Lx EN Adapter Card
- Third-party software persistence across upgrades
- Ability to enter a Stream ID for an SRT session

---

## MK.IO Beam 1.9.0.5

**24th April 2026**

### New Features

- Configuration of IP settings for bonded interfaces on the UI
- Creation and deletion of VLAN interfaces on the UI
- Configuration of IP settings for VLAN interfaces on the UI
- Configuration of route metrics on the UI to support multiple default gateways
- Configuration of jumbo frames on the UI to simplify JPEG-XS encode configuration
- Configuration of static routes on the UI
- 8 tuners supported on the 4-port RF input card (Digital Devices SX8)
- Dell SupportAssist information included in Beam support packages

---

## MK.IO Beam 1.8.0.3

**27th March 2026**

### New Features

- H.264 High added to the list of Contribution codecs
- Removal of the four-service limitation for SMPTE ST 2110 output
- Support for down conversion modes: 1080i to 720p, 1080p to 720p, 720p to 1080i, UHD to 1080i, UHD to 1080p, UHD to 720p
- Beam with distributed headends including Packaging
- Static routes configuration now retained on upgrade

---

## MK.IO Beam 1.7.0.4

**27th February 2026**

### New Features

- ST2022-6 output over IP
- UI configuration support for HTTPS Proxy
- Support for Multi-Payload SMPTE ST 2110-40 VANC Reception
- Reception — support for super low delay mode for 1080i video sources
- Packager redundancy in Beam using a failover group
- RF cards from Beam appliances now visible in the MK.IO Device page (similar to IP and SDI/ASI)
- BEAM with HA headends — support for Multiplexer redundancy

---

## MK.IO Beam 1.6.0.5

**30th January 2026**

### New Features

- Support for router control for headend deployments of MK.IO Beam
- HDR/SDR custom Look-up Table (LUT) upload and selection
- Ability to enable/disable Packaging from the MK.IO Beam UI
- CPIX integration using HMAC for live events and linear channels
- Alarms exposed to Prometheus for viewing on a remote Grafana instance
- Support for UHD decode over SMPTE ST 2110 output
- BEAM with HA headends — support for Packager and Live Encoder on separate servers
- HTTPS access to packaged output
- Splicing now supported in distributed headend deployments

---

## MK.IO Beam 1.5.0.4

### New Features

- Introduction of the X20 server
- Live-to-live splicing is now supported
- Support for backup and apply of device configurations from MK.IO

## MK.IO Beam 1.4.0.3

**31 October 2025**

### New Features

- Support for high availability headend deployments with Live Encoding
- Support for SD resolutions with SMPTE ST 2110 output
- Improvements to decode latency
- Bonding capability for all ports

## MK.IO Beam 1.3.0.0

**9 October 2025**

### New Features

- Introduction of X40 server
- Support for multiple CI option cards in a single chassis
- Software decode supports HDR to SDR dynamic range conversion
- Software decode support for additional sub-sampled resolutions for 720p- and 1080i-based content
- Support for running MK.IO Beam in a VM for controller use cases on ESXi virtualization
- Support for installing the MK.IO Beam software ISO via BMC or iDRAC
- PTP, clock source, and IGMP parameters configurable on the UI
- Network status information available on the UI

---

## MK.IO Beam 1.2.0.1

**5 August 2025**

### New Features

- Introduction of C30 and H70 servers
- Server pair 1+1 redundancy for headends
- Support for multiple Digital Devices RF input cards in a single chassis
- Receiver service support for AMD CPUs
- Simplified JPEG-XS encode configuration
- Support for ASI output on Dektec DTA-2127

---

## MK.IO Beam 1.1.0.2

**23 June 2025**

### New Features

- Support for E50 and E60 servers for contribution encode and headend use cases
- 4:2:2 8-bit and 10-bit progressive and interlaced H.264 and H.265 HD software encode
- RF input and SDI output via Dektec DTA-2127 RF input option card
- 4:2:2 and 4:2:0 H.265 UHD software decode
- 4:2:2 10-bit SMPTE ST 2110 output with software decode
- The Dektec DTA-2178 8-port SDI option card now supported with reception — up to 8 baseband outputs per card, more with multiple cards
- Hostname, IP, NTP, firewall zones, DHCP, and DNS parameters configurable on the MK.IO Beam web UI
- New "Super Low" decode delay mode for lower latency decoding
- Server health monitoring now available
- Support for active-backup redundant bonded network management interfaces
