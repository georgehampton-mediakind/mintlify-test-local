## Configuring a video output

A video output stream exists in the transport stream configuration. See [Configuring output transport stream elements](/beam/multiplexer/configure/transport-stream#configure-output-transport-stream-elements) for more information.

1. Display services.

2. Click <img src="/icons/ui/edit.svg" alt="Edit" className="mk-ui-icon" width="16" height="16" /> to edit the service and display parameters. The transport stream parameters display.

3. Select the service and add a video output to the transport stream if none exists, or select an existing video output to display **Properties**.

   ![view ts video properties sp](/_machine-assets/3d0b9c1ed80f630bfef5dc63d09609ad475676d7552f1e106fe0637dfa288c7c.png)
