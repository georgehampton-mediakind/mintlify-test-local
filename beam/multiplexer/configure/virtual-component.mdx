## Configuring a virtual component

A user can now add component and their descriptors for inclusion in the generated PSI with re-multiplexing and associated input PID. Virtual compoments are present as just another type of component like video and audio.

1. Display services.

2. Click <img src="/icons/ui/edit.svg" alt="Edit" className="mk-ui-icon" width="16" height="16" /> to edit the service and display parameters. The transport stream parameters display.

3. Select the service, then add and configure a virtual component to the service.

   ![view ts virtual component sp](/_machine-assets/7afd649d199066ebd588adf3a3e6a1ca2f232dabc62dd3d2bd290a39c49b6c16.png)

4. You can then add a component descriptor as per any other service output.
