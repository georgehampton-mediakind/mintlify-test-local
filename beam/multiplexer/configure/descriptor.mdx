## Configuring a service descriptor

1. Display services.

2. Click <img src="/icons/ui/edit.svg" alt="Edit" className="mk-ui-icon" width="16" height="16" /> to edit the service and display parameters. The transport stream parameters display.

3. Select the service and add a custom descriptor to the transport stream service if none exists, or select an existing descriptor to display **Properties**.

   ![view ts service descriptor properties sp](/_machine-assets/8f4681fa0109341c3d4b7872e63da0e67ee93e5b177e4daaaf81df46c1662458.png)

   1. Enter the service Name

   2. Enter the service provider name

   3. Select the service type in the drop-down list

   4. Select the regeneration mode for this descriptor when descriptor regeneration is on.

## Configuring a component descriptor

1. Click <img src="/icons/ui/edit.svg" alt="Edit" className="mk-ui-icon" width="16" height="16" />. The transport stream parameters display.

2. Select the component and add a custom descriptor to the transport stream component if none exists or select an existing descriptor to display **Properties**.

   ![view ts custom descriptor properties sp](/_machine-assets/087490078e25dfc328581cada6d53a49ea49cc9f18f6ebf7ac785ee7c5a55848.png)
