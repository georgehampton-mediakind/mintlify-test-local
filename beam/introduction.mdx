MK.IO Beam brings high-quality broadcast and streaming processing to the edge of your network. Each Beam appliance handles the demanding tasks of live video acquisition, decoding, and distribution while remaining connected to the MK.IO cloud portal for unified monitoring, remote control, and lifecycle management. Whether you are encoding feeds for satellite uplink, decoding incoming satellite services for monitoring, or processing channels for cable and IPTV distribution, Beam provides a flexible, future-proof solution that you can operate from a single cloud interface.

## What Beam Does

MK.IO Beam combines enterprise-grade broadcast hardware with software-defined processing:

- **Low-latency contribution encoding** — compress live video from SDI, SMPTE ST 2110, or IP sources up to 4:2:2 10-bit UHD for field-to-studio delivery.
- **Professional decoding and reception** — demodulate satellite signals (DVB-S/S2/S2X), decode compressed streams (HEVC, H.264, MPEG-2, JPEG-XS), and output baseband SDI or ST 2110.
- **Headend processing** — statistically multiplex, transcode, and package channels for cable, IPTV, and OTT distribution.

All workflows are managed through the MK.IO cloud portal, giving you device registration, remote UI access, software updates, configuration backups, and log collection without a truck roll.

## Essentials and Advanced UI

The Beam device UI is available in two modes, toggled from the header:

- **Essentials** — a simplified day-to-day operating view. Channels are presented as unified cards with live thumbnails, status indicators, and a single creation wizard. Use this for routine monitoring, alarm review, and channel management. Requires Beam version `1.12.0` or higher on a fresh installation.
- **Advanced** — a deep engineering view that exposes individual services, feed templates, servers, and alarm overrides. Use this for complex configuration, service-level tuning, and troubleshooting.

Both modes act on the same underlying system. A change made in one is immediately visible in the other.

<Note>
  A device presents one view or the other, never both. Devices running Essentials manage workflows as _channels_; devices without it manage them as _feeds_. If documentation refers to feeds, see the Advanced interface guides.
</Note>

## Connecting to MK.IO

After completing the hardware setup and network configuration, you register your Beam device with MK.IO. Registration enables:

- Remote device UI access through a secure MK.IO tunnel
- Software update delivery from the portal
- Configuration backup and restore
- Log collection for support packages

Before registration, ensure the device has a configured Control interface, a default gateway, DNS servers that resolve external domains, and an active time source.
