To create a new service, follow these steps:

1. From the **Services** page, click **Add service** then select **Live Encoding**.

2. Enter a service name.

3. You can [create the service from an existing template](/beam/live-encoder/create-service#create-a-service-from-a-template).

4. Start configuring or completing the service parameters:
   * **Input** (see [Configure the input](/beam/live-encoder/configure/input))
   * **Media Processing** (see [Configure the media processing](/beam/live-encoder/configure/media-processing/video-processing))
   * **Encoding** (see [Configure the encoding parameters](/beam/live-encoder/configure/encoding))
   * **Output** (see [Configure the output](/beam/live-encoder/configure/output/configure-output))

<Info>
  If you create a service from a template, some parameters are already configured. Enter any missing parameters (displayed in orange) and, if needed, modify the predefined ones.
</Info>

## Create a service from a template

Templates are a set of saved parameters that are based on an existing service configuration. You can create a new service from a template to automatically apply its configuration.

Before you start: ensure you have previously created one or more template(s).

1. From the **Services** page, click **Add service** then select **Live Encoding**.

2. In the **Template** drop-down list, select a template. Template parameters display. Missing parameters appear in orange.

3. Edit the missing parameters (in the **General**, **Input** and **Output** tabs) and, if needed, modify the predefined parameters.
