1. Display services.

2. Click <img src="/icons/ui/edit.svg" alt="Edit" className="mk-ui-icon" width="16" height="16" /> to edit the service. The **General parameters** display.

3. Select **Input** tab to display parameters.

4. Go to the **Sources** > **Input streams selection** > **Audio ID** section then click **Add** to configure a new audio stream or click <img src="/icons/ui/edit.svg" alt="Edit" className="mk-ui-icon" width="16" height="16" /> to edit an existing one.

5. Enter the appropriate value for each [audio stream parameter](/beam/live-encoder/parameters/input/video-and-audio#audio).

   <Info>
     Parameters differ depending on the selected input type.
   </Info>

6. Click **Ok**. The audio input is added to the list of audio inputs.

7. Click **Save and continue** or **Save and exit** to save your changes.
