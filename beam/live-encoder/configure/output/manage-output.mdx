## Add an output

You can create several outputs.
To create an output you can either:

* [Create a new one](/beam/live-encoder/configure/output/manage-output#create-a-new-output-from-scratch).
* [Duplicate an existing one](/beam/live-encoder/configure/output/manage-output#duplicate-an-existing-output).

### Create a new output from scratch

When connecting for the first time or if you want to add an output, you can create a new one from scratch.

To create an output, follow these steps:

1. From the **Output** tab, click the **Add** button. A new output section is created.

2. [Edit the output](/beam/live-encoder/configure/output/manage-output#edit-an-output).

3. Click **Ok** to save your changes. The new output is added in the output tab.

### Duplicate an existing output

You can create an output by duplicating an existing one.

To duplicate an output, follow these steps:

1. Click the duplicate icon <img src="/icons/ui/clone.svg" alt="Clone" className="mk-ui-icon" width="16" height="16" /> in the top right corner of the reference output. A new output section is created with the same parameters as the reference output.

2. If needed, you can [edit the output](/beam/live-encoder/configure/output/manage-output#edit-an-output)

3. Click **Ok** to save your changes. The new output is added in the output tab.

## Edit an output

Before you start, ensure an output exists.

If no output exists, see [Add an output](/beam/live-encoder/configure/output/manage-output#add-an-output).

1. From the **Output** tab, click **Output** to open the tab and display outputs.

2. Click <img src="/icons/ui/edit.svg" alt="Edit" className="mk-ui-icon" width="16" height="16" /> to display parameters and edit the output. The output parameters display.

<Info>
  Depending on your configuration type and settings, additional parameters may display.
</Info>

3. [Edit the general parameters](/beam/live-encoder/configure/output/configure-output#configure-the-output-stream-mpeg-2-ts-parameters).

4. [Configure the MPEG-2 TS parameters](/beam/live-encoder/configure/output/configure-output#configure-the-output-stream-mpeg-2-ts-parameters).

5. [Select the streams to include in the output.](/beam/live-encoder/configure/output/configure-output#define-the-output-stream-composition).

6. Click **Ok** to save your changes. The new output is added in the output tab.

## Delete an output

<Info>
  If deleted, the stream is automatically removed from any outputs.
</Info>

From the **Output** tab, click <img src="/icons/ui/delete.svg" alt="Delete" className="mk-ui-icon" width="16" height="16" /> in the top right corner of the selected output stream. A message asks you to confirm the deletion.
