---
title: Configure the input
sidebarTitle: Input
---

<span id="_top" className="mk-legacy-anchor" />

1. From the **services** page, click <img src="/icons/ui/edit.svg" alt="Edit" className="mk-ui-icon" width="16" height="16" /> to edit the service. The **General parameters** display.

2. Select **Input** tab to display parameters.

3. Enter the appropriate value for each [parameter](/beam/live-encoder/parameters/input/general).

<Info>
  Parameters may differ depending on the selected input type, especially SDI or SMPTE ST 2110 that have a limited number of parameters.
</Info>

4. You can [configure the source error management](/beam/live-encoder/configure/input/source-error-management).

5. [Configure source(s)](/beam/live-encoder/configure/input/input-stream-source): the primary source and optionally the secondary source.

6. Select a **Save** option to save changes.
