You can configure all network settings from the **System Settings** tab on the server information page. Navigate there by going to the **Servers** view, clicking the **Details** button to open server information, and then selecting the **System Settings** tab.

<Warning>
  Changes to network interface configuration can result in the device becoming unreachable. Plan changes carefully and ensure you have an alternative means of access if needed.
</Warning>

## Set the Hostname

<Steps>
  <Step title="Enter the Hostname">
    Enter the new hostname in the **Hostname** field on the System Settings page.
  </Step>
  <Step title="Save">
    Click **Save** at the bottom of the page.
  </Step>
</Steps>

## Set IP Addresses, Subnet Masks, Gateway, DHCP, and Firewall Zone

<Steps>
  <Step title="Open Network Device Settings">
    Go to the **Network devices** section on the System Settings page. Click the **Edit** button next to the interface you want to configure.
  </Step>
  <Step title="Configure DHCP">
    Enable or disable **DHCP**. When DHCP is enabled, the interface IP address and DNS servers are allocated automatically. DHCP-allocated values cannot be edited and are shown for reference only.
  </Step>
  <Step title="Set IP Address">
    If DHCP is disabled, enter the IP address and subnet mask in the **Addresses** field using CIDR notation.
  </Step>
  <Step title="Set Gateway (Optional)">
    Optionally, enter the default gateway in the **Gateway** field and a value in the **Gateway metric** field. Usually the gateway metric is left blank.
  </Step>
  <Step title="Set Firewall Zone (Optional)">
    Optionally, set the firewall zone. Valid values are **control**, **data**, or **control & data (public)**.
  </Step>
  <Step title="Save">
    Click **Confirm**, then click **Save** at the bottom of the page.
  </Step>
</Steps>

<Note>
  While you can configure multiple default gateways, this can cause routing issues. If you need to direct traffic for specific subnets, adding a static route is the recommended approach rather than configuring multiple gateways. If you do define multiple gateways, ensure the Control interface has the lowest gateway metric.
</Note>

## Configure Static Routes

Configuring static routes and gateway metric is available in Beam 1.9 and later. You can add static routes to an interface to direct traffic for specific subnets through a particular gateway.

<Steps>
  <Step title="Open Interface Settings">
    In the **Network devices** section, click the **Edit** button for the interface you want to configure.
  </Step>
  <Step title="Manage Static Routes">
    In the **Edit Network Device** dialog, go to the **Static routes** section:
    - To **add** a route, click **+ Add route**, enter the **Destination (CIDR)** and **Gateway**, then click **Add Route**.
    - To **edit** a route, click the **Edit** button next to it.
    - To **delete** a route, click the **Delete** button next to it.
  </Step>
  <Step title="Confirm and Save">
    Click **Confirm** in the Edit Network Device dialog, then click **Save** at the bottom of the System Settings page.
  </Step>
</Steps>

## Set DNS Addresses

<Steps>
  <Step title="Open DNS Settings">
    Go to the **DNS** section on the System Settings page. Click the **Edit** button next to the interface to open its DNS settings.
  </Step>
  <Step title="Add DNS Servers">
    If DHCP is disabled, add at least one DNS server in the **Addresses** field using CIDR notation. DNS servers allocated by DHCP cannot be edited and are shown for reference only.
  </Step>
  <Step title="Save">
    Click **Confirm**, then click **Save** at the bottom of the page.
  </Step>
</Steps>

## Set IGMP Version

<Steps>
  <Step title="Open IGMP Mode Settings">
    Go to the **IGMP mode** section on the System Settings page.
  </Step>
  <Step title="Select IGMP Version">
    From the drop-down, select **Automatic v2/v3** or **Force v2**.
  </Step>
  <Step title="Save">
    Click **Save** at the bottom of the page.
  </Step>
</Steps>

## Configure Bonded Interfaces

To configure active-backup bonded interfaces for redundancy, use the command-line procedure described in the Bonded Network Interfaces guide. Bonded interface IP settings can also be configured through the UI as of Beam 1.9.

## System Clock Configuration

The system clock is used by all applications on the server as a time reference for operations such as applying Over Air Commands, recording log entries, and synchronizing events across the system.

You can synchronize the system clock using NTP (suitable for co-located or well-connected units), TDT from a transport stream (suitable for remote or unreliably connected units), PTP, or free-running mode.

### Operating Modes

Configure the **Time Source** from the **System Settings** page on the web UI:

| Mode | Description |
| :-- | :-- |
| **Free Running** | The system clock increments based on the accuracy of the motherboard clock. |
| **NTP** | The server adjusts its clock based on messages from a configured NTP server. If NTP messages stop, the unit free-runs from its last known time. |
| **PTP** | The device synchronizes with a PTP Grand Master. |
| **TDT** | The server adjusts its clock based on the TDT within a selected transport stream service. |

All services and functions running on the server use a single system clock and are affected by the system clock setting.

### Configure NTP Servers

<Steps>
  <Step title="Open Time Sources">
    Go to the **Time sources** section on the System Settings page and select the **NTP** tab.
  </Step>
  <Step title="Add an NTP Server">
    Click **+ Add NTP server**, enter the NTP server's IP address in the **Address** field, then click **Confirm**.
  </Step>
  <Step title="Update an Existing Server">
    To update an existing server's IP address, click the **Edit** button next to that server, update the address, then click **Confirm**.
  </Step>
  <Step title="Activate NTP">
    Click **Make active** to set NTP as the time source, then click **Save** at the bottom of the page.
  </Step>
</Steps>

### Select the TDT Source

<Steps>
  <Step title="Open TDT Settings">
    Go to the **Time sources** section on the System Settings page and select the **TDT** tab.
  </Step>
  <Step title="Select the Service">
    Select the **Service name** from the drop-down menu.
  </Step>
  <Step title="Activate TDT">
    Click **Make active**, then click **Save** at the bottom of the page.
  </Step>
</Steps>

### Configure PTP Synchronization

For PTP synchronization, see the ST-2110 input setup guide for PTP configuration procedures.

### Set Free Running Mode

<Steps>
  <Step title="Open Free Running Settings">
    Go to the **Time sources** section on the System Settings page and select the **Free Running** tab.
  </Step>
  <Step title="Disable Time Synchronization">
    Click **Disable time synchronization**, then click **Save** at the bottom of the page.
  </Step>
</Steps>
