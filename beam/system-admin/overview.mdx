System administration for MK.IO Beam covers the management of the platform itself — the hardware, operating system, security settings, and platform services — rather than the media workflows running on it. Most of these tasks are performed via the **System Center** menu in the web interface, accessible via the gear icon in the top right corner.

## System Center

Management and administration features — including SNMP, SDI router connections, external links, LDAP configuration, backup and restore, and user management — are available in the **System Settings** menu (the gear icon ![Gear] in the top right corner).

The following tabs are available from the **Settings** menu:

- **General** — customize the system name and alarm display time
- **SNMP notifications** — configure alarm forwarding via SNMP
- **External links** — add links to third-party tools in the navigation
- **Router Settings** — connect to external SDI routers for input switching
- **LDAP** — integrate with Active Directory for centralized authentication

## System Name Customization

Administrators can customize the system name displayed in the user interface. This is particularly useful when multiple systems with distinct controllers manage separate servers and services.

<Steps>
  <Step title="Open Settings">
    Click the gear icon in the upper right corner, then select **Settings**.
  </Step>
  <Step title="Edit the System Name">
    In the **General** tab, enter the name to display for this system.
  </Step>
  <Step title="Save">
    Click **Save** to apply the changes. The new system name appears in the top left of the user interface.
  </Step>
</Steps>
