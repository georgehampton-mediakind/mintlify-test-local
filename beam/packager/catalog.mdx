A catalog is an inventory of one or more outputs on which the following delivery parameters are configured:

* **Catalog**'s **name** and **output types**
* **Delivery** parameters
* **Manifests**' **Filtering** parameters (audio, video and subtitle bitrates)
* **Encryption** parameters

<Warning>
  **Note**

  At least one output must be configured.
</Warning>

## Creating a new catalog

To create a new catalog, follow these steps:

1. Access the MK.IO Beam user interface.

2. Click **Services** in the left panel.

3. Click **Add service** > **Catalog**.

4. Enter the catalog name.

5. Do one of the following:

   * Click **Save and continue** to complete the catalog creation and start adding outputs.
   * Click **Save and exit** to save and finalize the catalog creation and go back to the **Services** page.
   * Click **Cancel** to go back to the **Services** page without saving.

## Adding an output to a Catalog

Once created, an output can be used by any Packager service for delivery.

#### Two output types are available:

To add an output to a Catalog, follow these steps:

1. From the **Services** page, click the **Name** related to the Catalog on which the output will be added.

2. Click **Add new output** then select the output type and configure the parameters according to your needs.

* [HLS or DASH over CMAF specific output settings](/beam/packager/hls-dash-over-cmaf-output)
* [HLS over TS (HTTP Live Streaming)](/beam/packager/hls-output)

3. **Save** configurations.
