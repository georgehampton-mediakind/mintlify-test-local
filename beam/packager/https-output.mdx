# Accessing MK.IO Beam Packaged Output Over HTTPS

The packaged output is optionally accessible via HTTPS. The Beam server must first be configured with certificates, see [Enable customer-signed SSL certificates](/beam/system-admin/security/ssl-certificates).

You can access packaged HTTPS output on port 8443 with the same URL path as used for HTTP access.
