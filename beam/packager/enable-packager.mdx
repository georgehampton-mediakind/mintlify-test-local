# Enable Packager in MK.IO Beam

To enable the Packager function in MK.IO Beam, follow these steps:

1. Click **Servers** in the left panel.
2. Click the **detail** icon <img src="/icons/ui/view.svg" alt="View" className="mk-ui-icon" width="16" height="16" /> in **Actions**.
3. Select the **Enable Live Packaging** check box. This is available under **General parameters**.
4. Once selected, click **Save** to apply the changes.
