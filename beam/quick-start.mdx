<span id="_top" className="mk-legacy-anchor" />

<Warning>
  Default credentials differ by purchase type:

  * **MK.IO Beam hardware purchased from MediaKind:** credentials are on the paper *Quick Start Guide* supplied with the hardware.
  * **SW Only:** credentials are in the email from SWSupply with a subject containing "Your recent MK.IO Beam purchase...".

  Change the default password after your first login. Select the user icon in the upper right corner of the device UI and choose **Change password**.
</Warning>

Complete the following steps to configure and register your MK.IO Beam device.

<Steps>
  <Step title="Install the ISO">
    <span id="install-the-iso" className="mk-legacy-anchor" />

    <Info>
      This step is required for SW Only customers only. The ISO is pre-installed on MK.IO Beam hardware purchased from MediaKind.
    </Info>

    See [Install the ISO](/beam/system-admin/iso-installation).
  </Step>

  <Step title="Set control IP address">
    <span id="set-control-ip-address" className="mk-legacy-anchor" />

    <Info>
      This step is only required if the device has not obtained a DHCP address. The IP address displays on the terminal when a monitor and keyboard are attached. Press Return if needed to clear the screen.
    </Info>

    1. Log in to the terminal with the default credentials.
    2. Type `control-wizard` and press Enter to configure the *Control* interface. You can also configure an HTTP proxy here if one is needed to reach MK.IO.
  </Step>

  <Step title="Connect to the web user interface">
    <span id="connect-to-the-web-user-interface" className="mk-legacy-anchor" />

    1. In a web browser, go to `http://<Control-IP-Address>`, where `<Control-IP-Address>` is the control IP address set in the previous step.
    2. Enter the default **username** and **password** on the login page.

    The **Home** page displays.
  </Step>

  <Step title="Configure the network">
    <span id="configure-the-network" className="mk-legacy-anchor" />

    See [Network Configuration](/beam/system-admin/network/configure-nics).

    Set at least one DNS server. DNS is required for connection to MK.IO unless you have configured an HTTP proxy.

    For the MK.IO connection requirements and device-management guides, see [Connect MK.IO Beam to MK.IO](/beam/connect-to-mkio).
  </Step>

  <Step title="Configure and activate time synchronization">
    <span id="configure-and-activate-time-synchronization" className="mk-legacy-anchor" />

    See [How to configure the system clock](/beam/system-admin/network/system-clock).

    Configure a time source and make it active.
  </Step>

  <Step title="Register the MK.IO Beam device with MK.IO">
    <span id="register-the-mkio-beam-device-with-mkio" className="mk-legacy-anchor" />

    See [device onboarding](/mkio/how-to/managing-edge-devices/on-board-fleet-devices).

    Registration status persists over an upgrade but does not persist if the device is re-imaged.
  </Step>

  <Step title="Upgrade to the latest software version">
    <span id="upgrade-to-the-latest-software-version" className="mk-legacy-anchor" />

    See [updating device software](/mkio/how-to/managing-edge-devices/update-device-software).
  </Step>
</Steps>
