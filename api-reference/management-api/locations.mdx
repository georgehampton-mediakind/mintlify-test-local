---
title: Locations
---

Locations represent the physical geographies where MK.IO currently has resources to run your workloads.

Locations can be either generally available (SaaS), or can be restricted to just one organization (Dedicated).

* [List available Locations](/api-reference/management-api/locations/list-available-locations)

* [Get Location](/api-reference/management-api/locations/get-location)
