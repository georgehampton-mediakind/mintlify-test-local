The MK.IO Live API provides live encoding and multiview capabilities for MK.IO. It covers template-based live channels and events, static multiview channels and events, and scheduled operations that let you start and stop resources at specific times. For templating, sources, destinations, assets, and streaming locators, consult the related [Templates API](/api-reference/templates-api) and [Media API](/api-reference/media-api).

<Info>
  **Version:** v0.0.23 · **Endpoints:** 41 · **Groups:** 5 · **Spec:** OpenAPI 3.0.2

  [Download OpenAPI spec](https://docs.mediakind.com/openapi/mkio/live-api.json)
</Info>

## Overview

MK.IO **Live Events** support multiple input sources, multiple audio profiles, source switching, 1+1 redundancy, and a multitude of codecs and coding parameters. **Live Channels** are identical to live events but use monthly billing for long-running workloads. Both can output to assets for instant Live2VOD, and destinations can be configured to contribute your stream over RTMP or SRT.

**Static Multiview Events** create a server-side tiled streaming experience for clients. Use Static Multiview to reach the broadest audience with support for H.264 and HEVC, SCTE-35 and SGAI, and DRM. Supported layouts include `2up`, `3up`, `3us`, `4up`, and `4us` — the number indicates connected sources, while `up` gives equal placement and `us` includes a spotlight.

**Static Multiview Channels** are the monthly-billing equivalent of Static Multiview Events.

All resources support **Scheduled Operations** to start and stop at specific times.

## Authentication

All endpoints require a bearer token in the `Authorization` header:

```http
Authorization: Bearer <your_token>
```

Create and manage your tokens in your [profile settings](https://app.mk.io/user/profile) under **Your personal API tokens**. See the [API tokens guide](/mkio/admin/api-tokens) for full instructions.

## Base URL

https://app.mk.io

## Endpoint Groups

### Live Channel — 10 endpoints

Manage long-running live channels with monthly billing, including scheduled start/stop operations and resource state.

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/api/v1/projects/{project_name}/live/liveChannels` | List Live Channels |
| `GET` | `/api/v1/projects/{project_name}/live/liveChannels/{name}` | Get Live Channel |
| `PUT` | `/api/v1/projects/{project_name}/live/liveChannels/{name}` | Create or Replace Live Channel |
| `PATCH` | `/api/v1/projects/{project_name}/live/liveChannels/{name}` | Update Live Channel |
| `DELETE` | `/api/v1/projects/{project_name}/live/liveChannels/{name}` | Delete Live Channel |
| `GET` | `/api/v1/projects/{project_name}/live/liveChannels/{name}/scheduledOperations` | List Scheduled Operations |
| `GET` | `/api/v1/projects/{project_name}/live/liveChannels/{name}/scheduledOperations/{operation_name}` | Get Scheduled Operation |
| `PUT` | `/api/v1/projects/{project_name}/live/liveChannels/{name}/scheduledOperations/{operation_name}` | Create or Update Scheduled Operation |
| `DELETE` | `/api/v1/projects/{project_name}/live/liveChannels/{name}/scheduledOperations/{operation_name}` | Delete Scheduled Operation |
| `GET` | `/api/v1/projects/{project_name}/live/liveChannels/{name}/state` | Get Resource State |
