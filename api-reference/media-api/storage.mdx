# Storage

The Storage API is how you tell MK.IO about the cloud storage that you use for your media assets.
You can add multiple Storage instances, associate credentials with them, and manage those credentials.
A Storage instance is a requirement to perform any meaningful activity within this platform.

All content is read from and written to your storage in your own cloud subscription!

This API supports Azure, AWS and GCP Storage.
