The MK.IO Templates API manages versioned encoding and composition configuration templates referenced by the Live API. Use it to discover available presets, create your own reusable configurations, and manage configuration versions. Live channels, live events, and static multiview resources all rely on templates to define their encoding parameters.

<Info>
  **Version:** v1.0.8 · **Endpoints:** 12 · **Groups:** 2 · **Spec:** OpenAPI 3.0.2

  [Download OpenAPI spec](https://docs.mediakind.com/openapi/mkio/templates-api.json)
</Info>

## Authentication

All endpoints require a bearer token in the `Authorization` header:

```http
Authorization: Bearer <your_token>
```

Create and manage your tokens in your [profile settings](https://app.mk.io/user/profile) under **Your personal API tokens**. See the [API tokens guide](/mkio/admin/api-tokens) for full instructions.

## Base URL

```
https://app.mk.io
```

## Endpoint Groups

### Templating — 9 endpoints

Create and manage versioned encoding and composition configurations. Each configuration is identified by its type and name, and versions are addressable by hash or tag.

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/api/v1/projects/{project_name}/templating/configs` | List the latest versions of all configurations |
| `GET` | `/api/v1/projects/{project_name}/templating/configs/{config_type}` | List the latest versions of configurations by type |
| `GET` | `/api/v1/projects/{project_name}/templating/configs/{config_type}/{name}` | Get the latest version of a configuration |
| `PUT` | `/api/v1/projects/{project_name}/templating/configs/{config_type}/{name}` | Create a new configuration or a new version |
| `DELETE` | `/api/v1/projects/{project_name}/templating/configs/{config_type}/{name}` | Delete all versions of a configuration |
| `GET` | `/api/v1/projects/{project_name}/templating/configs/{config_type}/{name}/versions` | Get all versions of a configuration |
| `GET` | `/api/v1/projects/{project_name}/templating/configs/{config_type}/{name}/versions/{version}` | Get a version by hash or tag |
| `DELETE` | `/api/v1/projects/{project_name}/templating/configs/{config_type}/{name}/versions/{version}` | Delete a version by hash or tag |
| `GET` | `/api/v1/projects/{project_name}/templating/types` | Get supported configuration types for this project |

<Note>
  Call `GET /templating/types` first to discover which configuration types your project supports before creating new templates.
</Note>

### Templating Presets — 3 endpoints

Read-only access to system-provided encoding presets. Use presets as a starting point when creating your own configurations.

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/api/v1/projects/{project_name}/templating/presets` | List the latest versions of all presets |
| `GET` | `/api/v1/projects/{project_name}/templating/presets/{config_type}` | List the latest versions of presets by type |
| `GET` | `/api/v1/projects/{project_name}/templating/presets/{config_type}/{name}` | Get the latest version of a preset |

## Example Requests

List all available configuration types for your project:

```bash
curl -X GET "https://app.mk.io/api/v1/projects/$MKIO_PROJECT/templating/types" \
  -H "Authorization: Bearer $MKIO_TOKEN"
```

List system-provided presets for a specific configuration type:

```bash
curl -X GET "https://app.mk.io/api/v1/projects/$MKIO_PROJECT/templating/presets/liveChannel" \
  -H "Authorization: Bearer $MKIO_TOKEN"
```

Get the latest version of a named configuration:

```bash
curl -X GET "https://app.mk.io/api/v1/projects/$MKIO_PROJECT/templating/configs/liveChannel/my-config" \
  -H "Authorization: Bearer $MKIO_TOKEN"
```

<Tip>
  Configuration versions are immutable. Creating a new version with `PUT` preserves the existing version history and makes the new version the latest. Reference a specific version by hash or tag to pin a Live resource to a known-good configuration.
</Tip>
