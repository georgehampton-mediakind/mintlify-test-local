The MK.IO Media API is the project-level REST API for managing media processing and delivery workflows in MK.IO. It provides endpoints for managing assets and storage, transforms and jobs, live events and outputs, streaming publication, filtering, and content protection. Most MK.IO integrations start here.

<Info>
  **Version:** v0.26.14 · **Endpoints:** 96 · **Groups:** 14 · **Spec:** OpenAPI 3.0.2

  [Download OpenAPI spec](https://docs.mediakind.com/openapi/mkio/media-api.json)
</Info>

## Authentication

All endpoints require a bearer token in the `Authorization` header:

```http
Authorization: Bearer <your_token>
```

Create and manage your tokens in your [profile settings](https://app.mk.io/user/profile) under **Your personal API tokens**. See the [API tokens guide](/mkio/admin/api-tokens) for full instructions.

## Base URL

```
https://app.mk.io
```

## Usage Pattern

The typical Media API workflow follows three stages:

<Steps>
  <Step title="Create or reference core resources">
    Register storage, create or reference assets, and define transforms with the encoding settings you need.
  </Step>
  <Step title="Run and monitor your workflow">
    Submit VOD jobs or start live events, then poll the resource state until processing completes.
  </Step>
  <Step title="Publish playback">
    Create a streaming locator linked to your asset, then call `listPaths` to retrieve the playback URLs.
  </Step>
</Steps>
