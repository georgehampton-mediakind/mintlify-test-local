The MK.IO Management API is the REST API for organization, project, and account administration in MK.IO. It supports governance and operational setup use cases, including managing users, teams, roles, and scopes; project and location management; payment methods; webhook rules; usage reporting; and profile and token operations. Most integrations call this API first to provision their environment before using the Media, Live, or Fleets APIs.

<Info>
  **Version:** v0.19.25 · **Endpoints:** 60 · **Groups:** 13 · **Spec:** OpenAPI 3.0.2

  [Download OpenAPI spec](https://docs.mediakind.com/openapi/mkio/management-api.json)
</Info>

## Authentication

All endpoints require a bearer token in the `Authorization` header:

```http
Authorization: Bearer <your_token>
```

Create and manage your tokens in your [profile settings](https://app.mk.io/user/profile) under **Your personal API tokens**. See the [API tokens guide](/mkio/admin/api-tokens) for full instructions.

## Base URL

```
https://app.mk.io
```

## Usage Pattern

<Steps>
  <Step title="Identify your organization and project context">
    Retrieve organization details and list available projects to confirm the target scope for your automation.
  </Step>
  <Step title="Manage access and permissions">
    Create and assign users, configure teams, set roles and scopes, and issue or revoke tokens.
  </Step>
  <Step title="Prepare for downstream API calls">
    Rotate tokens, assign payment methods to projects, and register webhook rules before calling the Media, Infrastructure, or Fleets APIs.
  </Step>
</Steps>

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/.well-known/jwks.json` | Get Public Keys |

## Example Request

```bash
curl -X GET "https://app.mk.io/api/v1/projects" \
  -H "Authorization: Bearer $MKIO_TOKEN"
```

<Tip>
  Create and assign a payment method to your project before running any workloads in the Media or Fleets APIs. The Management API's `/projects/{project_name}/paymentMethod` endpoints handle this in two calls.
</Tip>
