# Get started with MK.IO

Choose the workflow that matches your first goal. Each path takes you through a complete result and links to deeper guides when you need more control.

If MK.IO is new to you, start with [What is MK.IO?](https://docs.mediakind.com/mkio/getting-started/what-is-mkio) for a short explanation of live and Video on Demand (VOD) workflows.

Use the MK.IO portal for guided setup. Use the APIs when you need to automate the same resources.

### Publish your first VOD asset

### Choose the right API

## Prepare your account

[Section titled “Prepare your account”](https://docs.mediakind.com/mkio/getting-started/#prepare-your-account)

Complete these setup tasks before a live or VOD workflow requires them:

1. [Set up your account and first project](https://docs.mediakind.com/mkio/getting-started/account-setup-and-first-steps).
2. [Connect cloud storage](https://docs.mediakind.com/mkio/getting-started/connect-cloud-storage) for assets, outputs, and recordings.
3. [Learn the MK.IO portal navigation](https://docs.mediakind.com/mkio/getting-started/platform-navigation-and-key-features).

If your account and storage are already ready, start with one of the workflows above.
