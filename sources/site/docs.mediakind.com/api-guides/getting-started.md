# Get started with the APIs

Use these guides to choose the right API, create a personal token, and confirm your access with a first request.

[Which API to use](https://docs.mediakind.com/api-guides/getting-started/which-api)

### Which API to use

Match your workflow to the Media, Management, Fleets, or Infrastructure API.

[Authentication and tokens](https://docs.mediakind.com/api-guides/getting-started/authentication)

### Authentication and tokens

Create a personal API token and send it with your requests.

[Your first API call](https://docs.mediakind.com/api-guides/getting-started/first-api-call)

### Your first API call

Make one authenticated request to confirm your token and project access.
