# Router configuration

The **Router settings** window enables users to configure the router parameters by establishing the connection and control of the SDI Router. This is performed by setting the input labels and using these labels to map the inputs for the Live Encoder services.

The output connections must be configured to map the router outputs to the input SDI ports of the encoder servers.

## Display the router configuration settings

[Section titled “Display the router configuration settings”](https://docs.mediakind.com/beam/system-admin/network/router-configuration/#display-the-router-configuration-settings)

1. Click ![Gear][base64-image] to display the system center menu.

2. Click **Settings** > **Router settings**. The **Router settings** display.

 ![router display](https://docs.mediakind.com/_astro/router_display.BqBcTvub_Z1UvfY9.webp)

## Add a new router configuration

[Section titled “Add a new router configuration”](https://docs.mediakind.com/beam/system-admin/network/router-configuration/#add-a-new-router-configuration)

1. Click ![Gear][base64-image] to display the system center menu.
2. Click **Settings** > **Router settings**. The **Router settings** display.
3. Click **Add router**. The **Router Configuration** parameters display.
4. Enter the parameters to configure the router.

For more details on the parameters below, see [Router parameters](https://docs.mediakind.com/beam/system-admin/maintenance/parameters#router-parameters).

![view router configuration](https://docs.mediakind.com/_astro/view_router_configuration.BmzmQUkl_2ePLDd.webp)

5. Click **Create** to save the configuration and return to list of routers.

## Edit an existing router configuration

[Section titled “Edit an existing router configuration”](https://docs.mediakind.com/beam/system-admin/network/router-configuration/#edit-an-existing-router-configuration)

1. Click ![Gear][base64-image] to display the system center menu.
2. Click **Settings** > **Router settings**. The **Router settings** display.
3. Click ![Edit][base64-image] to edit the router configuration.

For more details on the parameters below, see [Router parameters](https://docs.mediakind.com/beam/system-admin/maintenance/parameters#router-parameters).

![router edit](https://docs.mediakind.com/_astro/router_edit.Dhg5plOp_ZdXXcx.webp)

4. Click **Update** to save the configuration and return to list of routers.

## Import a router configuration

[Section titled “Import a router configuration”](https://docs.mediakind.com/beam/system-admin/network/router-configuration/#import-a-router-configuration)

1. Click ![Gear][base64-image] to display the system center menu.

2. Click **Settings** > **Router settings**. The **Router settings** display.

3. Click **Import router**. The **Import Router** display appears, enabling you to import a router configuration file (yaml) from another system. ![import router](https://docs.mediakind.com/_astro/import_router.B-NqbDDB_Svd22.webp)

4. Click **Select file**.

5. Select the required file then click **Open**. The file appears in the **Import Router** window.

 ![import router json](https://docs.mediakind.com/_astro/import_router_json.ClDRChYk_Z2hVKRu.webp)

6. Click **Import**. The imported file displays in the list in the **Router settings** tab.

## Export a router configuration

[Section titled “Export a router configuration”](https://docs.mediakind.com/beam/system-admin/network/router-configuration/#export-a-router-configuration)

1. Click ![Gear][base64-image] to display the system center menu.
2. Click **Settings** > **Router settings**. The **Router settings** display.
3. Click ![Download][base64-image]. The **Downloads** window display appears showing the location of the exported router from which can now be used in another system.

## View router crosspoints

[Section titled “View router crosspoints”](https://docs.mediakind.com/beam/system-admin/network/router-configuration/#view-router-crosspoints)

1. Click ![Gear][base64-image] to display the system center menu.

2. Click **Settings** > **Router settings**. The **Router settings** display.

3. Click ![View][base64-image]. The **Router Crosspoints** display, showing the crosspoints set on the router.

4. Select the **Show uncontrolled** checkbox to view the state of the entire router, including the inputs and outputs that have not been labelled or connected.

5. Toggle between Auto **refresh** and **No refresh** to enable or disable an automatic refresh.

 ![router crosspoints](https://docs.mediakind.com/_astro/router_crosspoints.C8_ess69_1PCu8U.webp)

6. Click **Back** to return to **Router settings** tab.
