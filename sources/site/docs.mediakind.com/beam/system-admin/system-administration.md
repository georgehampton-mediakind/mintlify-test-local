# System administration

## System center

[Section titled “System center”](https://docs.mediakind.com/beam/system-admin/system-administration/#system-center)

Management and administration features such as SNMP, SDI routers, external links and LDAP configuration, as well as [backup and restore](https://docs.mediakind.com/beam/system-admin/maintenance/backup-restore) and [user management](https://docs.mediakind.com/beam/system-admin/security/user-management) are available in the **System Settings** menu, ![Gear][base64-image].

![menu mfvp system settings](https://docs.mediakind.com/_astro/menu_mfvp_system_settings.BHUHoTyA_ZVJ0WY.webp)

The following tabs are available from the **Settings** menu:

- **General**
- [**SNMP notifications**](https://docs.mediakind.com/beam/system-admin/maintenance/alarms-events#alarm-forwarding-snmp)
- [**External links**](https://docs.mediakind.com/beam/web-interface/navigation#external-links-to-third-party-tools)
- [**Router Settings**](https://docs.mediakind.com/beam/system-admin/network/router-configuration)
- [**LDAP**](https://docs.mediakind.com/beam/system-admin/security/ldap-management)

From the **General** tab, you can customize the system name (see below) and the [alarm display time](https://docs.mediakind.com/beam/system-admin/maintenance/alarms-events#customize-alarm-display-time).

## System name customization

[Section titled “System name customization”](https://docs.mediakind.com/beam/system-admin/system-administration/#system-name-customization)

Administrators have rights to edit and customize system name displayed in the user interface. Depending on deployed solutions or environment, multiple systems including distinct controller(s) managing separate servers and services may be necessary. Customizing the system name allows you to easily identify from the home page the system you need to access.

1. Click ![Gear][base64-image] in the upper right corner.
2. Select **Settings**. The Settings page displays 5 tabs:
3. In the **General** tab, enter the name to display for this system and click **Save** to apply the changes. The new system name displays on the top left side of the system user interface.
