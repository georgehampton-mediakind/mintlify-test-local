# Processing Types

# Enable or Disable Processing Types

[Section titled “Enable or Disable Processing Types”](https://docs.mediakind.com/beam/system-admin/maintenance/processing-types/#enable-or-disable-processing-types)

To optimize resource utilization on a Beam unit, especially on lower-spec units, you can enable or disable certain processing types. Disabling unused functionalities can free up RAM and CPU, improving throughput for the tasks you are running.

The specific processing types available for configuration may change over time as the Beam platform evolves.

## How to change processing types

[Section titled “How to change processing types”](https://docs.mediakind.com/beam/system-admin/maintenance/processing-types/#how-to-change-processing-types)

To enable or disable a processing type:

1. Click **Servers** in the left panel to see the list of units in your cluster.
2. For the desired unit, click the **detail** ![View][base64-image] button in the **Actions** column.
3. Locate and select or deselect the checkboxes for the processing types you want to enable or disable. These are listed under **General Parameters**.
4. Click **Save** to apply the changes.
