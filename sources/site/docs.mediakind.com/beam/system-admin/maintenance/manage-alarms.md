# Manage alarms

When the feed is running:

- If no alarm is raised, you should have the following:

 ![ce1 channel playing noAlarm](https://docs.mediakind.com/ce1-img/ce1_channel_playing_noAlarm.png)

- If one or more alarms are raised, a color alarm indicator along the top of the feed is shown. The alarm indicator takes the color of the active alarm with the highest level of severity.

 You can click the alarm icon on each component to go to the alarms page for that component.

 ![ce1 channel alarms critical](https://docs.mediakind.com/ce1-img/ce1_channel_alarms_critical.png)

If you select a component, you will access the related alarm page that will display the active alarms and the alarm history.

## Show alarms in local time

[Section titled “Show alarms in local time”](https://docs.mediakind.com/beam/system-admin/maintenance/manage-alarms/#show-alarms-in-local-time)

Alarm times can be displayed in local time instead of UTC.

To configure this, click ![Gear][base64-image] in the top right corner then select the **Settings** menu. From the **General** tab, set the **Alarm display time zone** to the required time zone.

![alarms local](https://docs.mediakind.com/ce1-img/alarms-local.png)
