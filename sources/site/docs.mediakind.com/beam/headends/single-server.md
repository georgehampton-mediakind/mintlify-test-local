# MK.IO Beam for headends, single server

[Section titled “MK.IO Beam for headends, single server”](https://docs.mediakind.com/beam/headends/single-server/#mkio-beam-for-headends-single-server)

A single server installation of MK.IO Beam can provide limited redundancy through redundant/multiple outputs of a Live Encoding service, offering a pair of sources to a Multiplexer service, which in turn can offer redundant multiple transport stream outputs.

![BeamHeadendSingleServer](https://docs.mediakind.com/beam-img/BeamHeadendSingleServer.png)

Reliable Transport services can optionally be used to provide services for ingress to the solution, or egress from the solution.
