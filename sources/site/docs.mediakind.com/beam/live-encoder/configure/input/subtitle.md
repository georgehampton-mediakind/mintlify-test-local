# Configure subtitle in input stream

To configure the input stream subtitle parameters, follow these steps:

1. Display Services.

2. Click ![Edit][base64-image] to edit the service.

3. From the **Input** tab, scroll to **Input stream selection** > **Subtitle ID** and click **Add**.

4. [Set Subtitles options](https://docs.mediakind.com/beam/live-encoder/parameters/input/subtitle), then click **OK** to save.

Subtitles are automatically added to the **Encoding** tab in pass-through only.

- You can [configure subtitle encoding parameters](https://docs.mediakind.com/beam/live-encoder/configure/encoding/subtitles-encoding).
- You can [configure subtitle burn-in](https://docs.mediakind.com/beam/live-encoder/configure/encoding/subtitle-burnin-encoding).
- You can [add subtitles to output streams](https://docs.mediakind.com/beam/live-encoder/configure/output/configure-output#define-the-output-stream-composition).
