# Configure video in input stream

To select a video stream, follow these steps:

1. Display services.

2. Click ![Edit][base64-image] to edit the service. The **General parameters** display.

3. Select the **Input** tab.

4. Go to the **Sources** > **Input streams selection** > **Video ID** section, then enter the appropriate value for each [video stream parameter](https://docs.mediakind.com/beam/live-encoder/parameters/input/video-and-audio#video):

 - **Video PID** (PID is only configurable if **Input synchronization mode** is set to **PidLocked** mode.)

 - **Decoding capability**

 - In case of **SMPTE ST 2110** input type, **Stream Index** and **SDP File Location**.

5. In [IPTV export type](https://docs.mediakind.com/beam/live-encoder/configure/encoding), you can delete the video input to get an audio-only service.

6. Click **Save and continue** or **Save and exit** to save your changes.
