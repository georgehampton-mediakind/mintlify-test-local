# Configure VANC in input stream

To configure a VANC data input stream, follow these steps:

Only available with **SMPTE ST 2110** input type.

1. Display services.

2. Click ![Edit][base64-image] to edit the service. The **General parameters** display.

3. Select **Input** tab.

4. Set the input type to **SMPTE ST 2110**.

5. Go to the **Sources** > **Input streams selection** > **VANC ID** section then click **Add** to configure the VANC data selection or click ![Edit][base64-image] to modify an existing one.

6. Enter the appropriate value for each \[VANC data parameter\](./parameters/input#VANC data parameter).

7. Click **OK**. The ANC data input is added to the list of VANC data inputs.

8. Click **Save and continue** or **Save and exit** to save your changes.
