# Configure the audio encoding parameters

Audio encoding parameters are only available if you defined an audio input from the **Input** tab.

1. Click **Add** to create a new audio encoding, or click ![Edit][base64-image] to edit an existing one. The **Encoding audio** window displays.

2. Select your audio **Codec** in the drop-down list. Depending on the selected audio codec, different parameters may display.

 **Pass-Through** lets you receive an already encoded stream and forward it to the output.

3. Enter the appropriate value for [audio encoding parameters](https://docs.mediakind.com/beam/live-encoder/parameters/encoding/audio).

4. Click **Save and continue** or **Save and exit** to save your changes.
