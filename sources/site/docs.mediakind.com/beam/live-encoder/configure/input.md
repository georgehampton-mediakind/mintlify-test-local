# Configure the input

1. From the **services** page, click ![Edit][base64-image] to edit the service. The **General parameters** display.

2. Select **Input** tab to display parameters.

3. Enter the appropriate value for each [parameter](https://docs.mediakind.com/beam/live-encoder/parameters/input/general).

Parameters may differ depending on the selected input type, especially SDI or SMPTE ST 2110 that have a limited number of parameters.

4. You can [configure the source error management](https://docs.mediakind.com/beam/live-encoder/configure/input/source-error-management).

5. [Configure source(s)](https://docs.mediakind.com/beam/live-encoder/configure/input/input-stream-source): the primary source and optionally the secondary source.

6. Select a **Save** option to save changes.
