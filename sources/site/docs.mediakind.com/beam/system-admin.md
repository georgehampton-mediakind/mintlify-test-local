# System Administration

This section covers the management of the BEAM platform itself (the hardware, operating system, security, and more), rather than the media workflows running on it.

The majority of these tasks are performed via the **System Center** menu in the web interface (accessed via the gear icon in the top right corner).

## Server Management

[Section titled “Server Management”](https://docs.mediakind.com/beam/system-admin/#server-management)

Manage the physical or virtual notes in your BEAM cluster.

[Manage Servers](https://docs.mediakind.com/beam/system-admin/servers/servers)

### Manage Servers

Add, remove, or reboot nodes.

[Failover Groups](https://docs.mediakind.com/beam/system-admin/servers/failover)

### Failover Groups

Configure redundancy groups for automatic failover.
