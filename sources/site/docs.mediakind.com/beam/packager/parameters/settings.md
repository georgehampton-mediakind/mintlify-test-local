# Packager settings

Below are the parameters accessed in the Packager settings.

## Credentials

[Section titled “Credentials”](https://docs.mediakind.com/beam/packager/parameters/settings/#credentials)

### User type

[Section titled “User type”](https://docs.mediakind.com/beam/packager/parameters/settings/#user-type)

| Parameter | Description |
| --- | --- |
| URL | Server URL. |
| Username | The user name to access the server. |
| Password | The password associated to the user name accessing the server. |

### Crypto type

[Section titled “Crypto type”](https://docs.mediakind.com/beam/packager/parameters/settings/#crypto-type)

| Parameter | Description |
| --- | --- |
| URL | Server URL. |
| Key seed | Key seed used to decrypt the content. |
