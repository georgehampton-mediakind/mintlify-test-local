# Configuring Live Packaging services

## Creating a new Live Packaging service

[Section titled “Creating a new Live Packaging service”](https://docs.mediakind.com/beam/packager/live-packaging-service/#creating-a-new-live-packaging-service)

To create a new Live Packaging service, follow these steps:

1. Access the MK.IO Beam user interface and click **Services** in the left panel.

2. Click the **Add service** button, then select **Live Packaging**.

3. You can configure the [parameters](https://docs.mediakind.com/beam/packager/parameters/live).

## Starting a Live Packaging service

[Section titled “Starting a Live Packaging service”](https://docs.mediakind.com/beam/packager/live-packaging-service/#starting-a-live-packaging-service)

**To start a Live Packaging service, you need to have previously configured**:

- A Catalog that contains at least one output ([Adding an output to a Catalog](https://docs.mediakind.com/beam/packager/catalog#adding-an-output-to-a-catalog)).
- A Live Packaging service that:
 - contains at least one source and a publishing point ([DVR](https://docs.mediakind.com/beam/packager/parameters/live#dvr)).
 - is linked to an existing Catalog.

**To start a Live packaging service, follow these steps:**

1. Access the MK.IO Beam user interface then click **Services** in the left panel.

2. Assign the service to a server. (Remember: A server must be assigned to Start the service.)

3. Click the ![Play outline][base64-image] button in the **Actions** column to start the related service.

The service status turns from **stopped** to **started**. The service starts publishing the DVR as configured.

## Stopping a Live Packaging service

[Section titled “Stopping a Live Packaging service”](https://docs.mediakind.com/beam/packager/live-packaging-service/#stopping-a-live-packaging-service)

In a solution deployment with servers, any Live Packaging service associated to a Live Encoding service must be stopped and started again after a modification of the Live Encoding configuration. The associated DVR must also be deleted.

To stop a Live Packaging service, follow these steps:

1. Go to the **Actions** column.

2. Click the ![Stop outline][base64-image] button to stop the related service.

The service status turns from **started** to **stopped**. The service stops publishing the DVR.

The origin server will return 404 errors 60 seconds after the DVR is stopped.

## Deleting a Live Packaging service and managing DVR

[Section titled “Deleting a Live Packaging service and managing DVR”](https://docs.mediakind.com/beam/packager/live-packaging-service/#deleting-a-live-packaging-service-and-managing-dvr)

Depending on the context, deleting a Live Packaging service by clicking ![Delete][base64-image] in the **Actions** column has different behaviors and results.

A Live Packaging service with the ![Play outline][base64-image] (started) status cannot be deleted. Click the ![Stop outline][base64-image] button to stop the service.

### The Live Packaging service has no server assigned

[Section titled “The Live Packaging service has no server assigned”](https://docs.mediakind.com/beam/packager/live-packaging-service/#the-live-packaging-service-has-no-server-assigned)

- The service configuration is deleted and removed from the service list. It cannot be recovered after deletion.
- The DVR generated by the service remains on the storage point.
