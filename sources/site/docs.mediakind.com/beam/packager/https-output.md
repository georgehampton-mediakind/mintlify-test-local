# Accessing MK.IO Beam Packaged Output Over HTTPS

[Section titled “Accessing MK.IO Beam Packaged Output Over HTTPS”](https://docs.mediakind.com/beam/packager/https-output/#accessing-mkio-beam-packaged-output-over-https)

The packaged output is optionally accessible via HTTPS. The Beam server must first be configured with certificates, see [Enable customer-signed SSL certificates](https://docs.mediakind.com/beam/system-admin/security/ssl-certificates).

You can access packaged HTTPS output on port 8443 with the same URL path as used for HTTP access.
