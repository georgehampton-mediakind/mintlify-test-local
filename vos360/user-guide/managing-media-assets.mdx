VOS360 supports both automatic and manual ingest and transcoding of file-based assets using the Asset Acquisition app.

<Note>
  **Important:&#x20;**&#x48;armonic recommends that you delete file-based assets that are no longer needed to reduce the storage consumption
</Note>

<Note>
  **Note:&#x20;**&#x42;y default, the maximum number of concurrent transcoding jobs is 100. If your workflow requires that more than 100 jobs be processed concurrently, contact Harmonic technical support for assistance.
</Note>
