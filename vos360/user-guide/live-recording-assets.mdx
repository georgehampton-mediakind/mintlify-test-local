You can create, monitor, and manage a variety of recordings from your live services in the Recording tab. The functionality allows you to manage recordings from past events and the events scheduled for the future.

![](/images/vos360/c70e386990b63783be32b8e4.png)

1. Click the **Asset Acquisition** app.

2. Navigate to the **Incoming&#x20;**&#x74;ab > **Recording&#x20;**&#x74;ab.

3. From the **List of live services&#x20;**&#x73;ection, select the service you want to create a recording from.

   * Click the ![](/images/vos360/797b38ba455a42b786c63107.png) button to schedule the recording.

     ![](/images/vos360/cd34150a2a64fbfa515e4620.png)

   * Select your time reference at the top of the page. Choose from the following:

     * **UTC**: Select this option to reference the time in Coordinated Universal Time. The format for this option is YYYY:MM:DD HH:MM:SS.xxx

     * **Local**: Select this option to reference the time based on your device's local time zone. The format for this option is YYYY:MM:DD HH:MM:SS.xxx

     * **TimeCode**: Select this option to reference the time based on the clip's time code. The format for this option is YYYY:MM:DD HH:MM:SS;FF

   * Use the slider to select the time segment and click **Preview**.

   * Specify the **Asset ID**/**Title&#x20;**&#x6F;f the recording to be created.

   * Specify the desired **Start Time&#x20;**(Time-In) and **End Time&#x20;**(Time-Out) to schedule the recording duration. You can fine-tune these values to ensure frame accuracy.

   * Click the **Go to&#x20;**&#x62;utton to preview the **Start Time&#x20;**&#x61;nd **End Time&#x20;**&#x66;rames.

   * **Pause&#x20;**&#x74;he preview and click the **Set&#x20;**&#x62;utton to confirm the configured **Start Time&#x20;**&#x61;nd **End Time**.

   * You can also enter the **Start Time** and **End Time** manually if the preview is not yet available.

   * Click the **Capture&#x20;**&#x62;utton to capture the recording as scheduled.

4. From the **List of recordings** section, check the status and type of the recordings.

   * Filter the list of recordings with the statuses: Queued, Processing, Submitted, Finished, Failed.

   * Filter the list of recordings with the types:

     * **LLCU**: This filter lists the Long-lasting catch-up (LLCU) recording assets.

     * **Loop Record**: This filter lists the loop recordings for Playout (ECU-based) playout recording assets.

     * **Live Event Record**: This filter lists the Live Event recording assets. (Refer to **Configuring a live-event service for recording** for Live Event recording details.)

   * Click![](/images/vos360/99576deeb5d5fbcf14f9a2e5.png) to verify the recording\
     ![](/images/vos360/322e28c8a7c38580419aebb3.png)

   * Upon successful recording, the assets are automatically saved to your Library.

   * (Optional) Navigate to the Library tab to use the Clip Editor to modify the asset. For more information, see "Removing unwanted content from assets" on the [Library](https://confluence360.video.harmonicinc.com/wiki/spaces/V360DD/pages/361040822/Library) page.

   * Click the **View in Library** button to view the recorded asset details.

   * (Optional) Delete any unwanted recordings.
