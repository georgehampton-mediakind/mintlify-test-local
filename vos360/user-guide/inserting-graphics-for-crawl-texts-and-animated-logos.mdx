---
title: Inserting graphics for crawl texts and animated logos
robots: noindex, nofollow
---

You can use HTML5 templates (.zip files) which can be used to enable crawl texts and animated logos.

From **Configure Broadcast** app, at multiplexer level, do the following:

<Note>
  **Note:&#x20;**&#x54;his graphics add-on is also applied to the service level.
</Note>

1. Click the **Edit&#x20;**&#x62;utton of the program.

2. Select the **Transcoding&#x20;**&#x74;ab.

3. From the **Graphics&#x20;**&#x61;dd-on, click the **Configure** button.

4. (Optional) Enter the template parameter for enabling text crawls.\
   ![](/images/vos360/c7129fb803647e14b52b6c8d.png)

5. Click the ![](/images/vos360/f4409451f93e0d882ea54d49.png) icon to select the Graphic Template.

6. (Optional) From the **Upload by URL&#x20;**&#x74;ab, you can use an external Web server URL to download the .zip file that contains the HTML5 template.

   <Note>
     **Note:&#x20;**&#x57;hen using **Upload by URL**, the reference URL is watched. If the .zip file is updated, the HTML5 template will be updated automatically.
   </Note>

   ![](/images/vos360/df0c10f87e5ee6198157efec.png)

7. (Optional) From the **File Uploader** tab, you can drag-and-drop to upload your file to VOS360, allowing the crawl texts or animated logos to download with local storage (no need for an external Web server).

   <Note>
     **Note:&#x20;**&#x57;hen using **File Uploader**, the HTML5 template is uploaded into VOS360 manually. You need to upload the .zip file manually if the HTML5 template is updated.
   </Note>

   ![](/images/vos360/62d582a56d6e77db88891916.png)

8. Click **Apply**.
