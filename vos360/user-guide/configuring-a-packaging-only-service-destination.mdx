**Before you begin**\
[Configuring a source input](/vos360/user-guide/configuring-a-source-input)

Configure a destination for Origin Server/Content Delivery Network (CDN) services.

<Note>
  **Note:&#x20;**&#x4D;ultiscreen service destinations support a single output.
</Note>

1. From the **Configure Channels** app, navigate to the **Destinations** page, click **+ Destination**.\
   ![](/images/vos360/b4161573952d57fc225909e8.png)

2. For **Destination Name**, type the name of the new destination.

3. For **Type**, select **Origin/CDN**.

4. For **Profile**, select the desired **Multiscreen** profile.

5. If the destination profile used supports push packaging, then configure the following settings for each OTT package output (DASH, HLS, and/or MSS):

8. For the destination profile with CMAF-Ingest publishing, configure the following settings under **CMAF-Ingest&#x20;**&#x70;ackaging:

   * Configure Compatibility Mode, Streaming Protocol, Primary Publishing Mode, and Redundancy Mode as desired.

9. If the service will be encrypted and you want to be able to monitor clean video output, select **Output Monitor** and provide the delivery **IP address** and **Port** for monitoring.

10. Ensure that **Status** is set to **Mandatory**, as this is the only output defined for the service so it must be the active output.

11. Click **Create**.
