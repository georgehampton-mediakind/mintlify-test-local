You can also register a CloudLink using VOS CLI in addition to Terminal UI.

1. Navigate to VOS and click **Settings** > **Client Apps** to create the client credentials.

2. Click th&#x65;**&#x20;Add client** button and create a client app with the following:

   1. Enable both the **Authorization code** and **Client credential** checkboxes.

   2. Specify a redirect URL (e.g. [https://localhost:38001/oauth/authorizationCode](https://localhost:38001/oauth/authorizationCode))

3. Initialize the VOS CLI and register the CloudLink to VOS Runtime in Okta mode with the following commands.
