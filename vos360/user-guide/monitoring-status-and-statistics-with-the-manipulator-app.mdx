## Status page

The Status page displays the overall status of the variant channels configured on the Manipulator app. The page also provides a quick way to view the logs and metrics of a particular variant channel.

[![](/images/vos360/f479abef4ddd0e5eb520861d.png)](/vos360/user-guide/monitoring-status-and-statistics-with-the-manipulator-app)

## Logs page

The Logs page displays detailed metrics and logs about variant channel requests.\
The metrics and logs can be filtered by particular variant channel, either through a shortcut on the Status page or by manually adding a Kibana filter on **service\_id**.
