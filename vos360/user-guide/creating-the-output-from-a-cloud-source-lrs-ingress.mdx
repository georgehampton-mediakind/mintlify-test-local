---
title: Creating the output from a cloud source (LRS ingress)
robots: noindex, nofollow
---

1. From the **Syndicate** app, click **+Cloud Source**.

2. Enter the following:

   1. Cloud Source name.

   2. Region. Make sure that this is the same region as the VOS360 cluster.

   3. Source protocol: Choose **SRT**.

   4. Decryption type. Choose from the following:

      1. No Encryption

      2. AES 128

      3. AES 192

      4. AES 256

3. Click **Create**.

4. Click **Copy URL** under the Cloud Source Ingest Endpoint field. This URL is used when configuring the mux service SRT destination.
