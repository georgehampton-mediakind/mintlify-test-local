You can use the graphics insertion panel in the Playout monitor to quickly add graphics over a playlist.

## Enable the graphics insertion panel

To display the graphics insertion panel, do the following:

1. Click the gear icon on the top left of the window to open the **Settings, Widgets, and Actions** menu.

2. Select **Channel**.

3. Switch the Display graphics insertion panel toggle to **Yes**.

## Using the graphics insertion panel

![graphics\_insertion\_panel.png](/images/vos360/442e71dfbe78b29706e82b22.png)

To add a graphic to a playlist, do the following:

1. Switch the **Config&#x20;**&#x74;oggle to **On**.

2. Drag and drop any graphic from the **Graphics&#x20;**&#x74;ab of the **Assets, Graphics, Feeds, and Sequences** area onto the graphics insertion widget.

3. Enter the following information in the **New graphic insertion button** window:

   1. Select the **Layer** for the graphic. Options range from 1 to 8.

   2. Optionally, enter a **Button name** for the graphic.\
      **Note:** Any name change does not affect the name of the file on the backend.

   3. For HTML graphics, you can also enter the following:

      1. Select the **Stop Mode**. Options are **Unload** or **Stop**.

      2. Optionally, click **Boxes** to open a field of parameters, if the HTML5 templates has been designed accordingly. Each parameter is rendered with all graphics animations.

4. Click **Apply**.

<Note>
  **Notes:**

  * You can insert up to four graphics per Playout monitor user interface.

  * To modify any graphics insertion parameters or to remove the graphic, click the pencil icon next to the name of the graphic.

  * You cannot modify the graphic of an existing graphic insertion.

  * Deleting a graphic insertion that is on-air does not stop the graphic.

  * Modifying an on-air graphic insertion won’t change the on-air graphic, it only changes the configuration.
</Note>

## Starting and stopping graphics

To start or stop graphics, do the following:

1. Verify that **Edit mode** is **On** on the top right of the window.

2. Switch the **Config&#x20;**&#x74;oggle to **Off**.

3. Click the **Play&#x20;**&#x74;riangle next to the graphic you want to play.\
   **Note:** If an on-air graphic is playing on the same layer as the one you start, the new graphic replaces the previous graphic.

4. Click the **Stop&#x20;**&#x73;quare to stop the graphic.

<Note>
  **Note:** You can modify the display mode of the graphics by clicking the menu next to the Config toggle. Options include the following:

  * **List view:** The default view. Displays the graphics in a top-down list.

  * **Icon view:** Displays the graphics as small icons. The Start and Stop buttons are overlayed on these icons when you hover over them.

  * **Large icon view:** Displays the graphics as large icons. The Start and Stop buttons are overlayed on these icons when you hover over them.
</Note>
