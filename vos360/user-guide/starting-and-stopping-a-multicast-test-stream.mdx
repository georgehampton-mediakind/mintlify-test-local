---
title: Starting and stopping a multicast test stream
robots: noindex, nofollow
---

Start and stop a multicast test stream using the Terminal UI commands.

1. From Terminal UI, press **i** to access the TUI command line.

2. From the Terminal UI command line, type `start stream` and press **Enter**.\
   &#x20;**Result**: A test stream will begin running on the multicast address 224.1.1.1, port 12345.

3. When you are finished, press **i** to access the TUI command line.

4. From the Terminal UI command line, type `stop stream` and press **Enter**.
