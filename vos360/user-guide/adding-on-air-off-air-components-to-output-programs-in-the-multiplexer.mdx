---
title: Adding on-air/off-air components to output programs in the multiplexer
robots: noindex, nofollow
---

In the Configure Broadcast app, you can add on-air/off-air pass-through components to the output programs in the Multiplexer created. The off-air components will be displayed in the output but disabled for output processing.

1. Click the **Configure Broadcast** app.

2. From the **Source&#x20;**&#x70;anel on the left, drag and drop the source to the **Multiplexer&#x20;**&#x63;reated on the right. See [Adding and configuring a multiplexer](/vos360/user-guide/adding-and-configuring-a-multiplexer) for more information.

   ![](/images/vos360/ab3ff6c424e6edd13c40d0bd.png)

3. Configure the transcoding service added to the multiplexer.

4. Drag and drop the component from the source to the **Output Programs Processing&#x20;**&#x69;n the Multiplexer you have created. \
   A new window appears.

   ![](/images/vos360/b77a033b5859c038f0eda539.png)

5. Configure the **Status&#x20;**&#x74;oggle to create the **Off-Air**/**On-Air&#x20;**&#x63;omponents accordingly.

6. Click the **+Add&#x20;**&#x62;utton to confirm.

   <Note>
     **Note:&#x20;**&#x41;n off-air component still appears in the **Output Programs Processing,** with the same information (type, output PID, etc.), but is shown in grey with no bold text.
   </Note>

   ![](/images/vos360/c48bcf5d29c67d9d76e71276.png)
