MP4 audio grooming profiles can be applied to MP4 sources.

**Before you begin**\
Make sure that you have configured system languages in **Configure Channels&#x20;**&#x61;p&#x70;**&#x20;> Settings&#x20;**&#x74;ab.

1. Navigate to the **Asset Acquisition** app > **Settings** tab > **Profiles**.

2. Click the **Create&#x20;**&#x62;utton to create an MP4 grooming profile.

3. Enter a **Profile Name**.

4. Select how the grooming profile should be applied to the source audio:

   * **Update missing fields only**

   * **Override all fields**

5. On the **Audio** tab, configure the following settings for each audio track:

   * **Languages**: Configure the languages to be used.

     <Note>
       **Note:&#x20;**&#x46;or playout assets, the languages you define for each audio and subtitle track must match the languages defined in the playout source.
     </Note>

   * **Type**: Select from the following:

     * **Not defined**

     * **Clean effects**

     * **Hearing impaired**

     * **Visual impaired commentary**

6. On the **Subtitles** tab, click **Add**, and configure the following settings:

   * **ID**

   * **Type**

   * **Page**

   * **Language**

7. Click **Save**.
