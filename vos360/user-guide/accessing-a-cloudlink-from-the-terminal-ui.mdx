title: Accessing a CloudLink from the Terminal UI
robots: noindex, nofollow
---

Using the vSphere Client, launch a virtual machine console running Terminal UI to access a CloudLink.

1. From the Windows Desktop on a computer where the vSphere Client is installed, click **Start**.

2. From the **Start** menu, click **VMware vSphere Client**.

3. From the **VMware vSphere Client** dialog box, in the **IP address / Name** field, enter the virtual machine management IP address.

4. In the **User name** and **Password** fields, type the username and password for your virtual machine login and click **Login**.

5. In the vSphere Client, expand the IP Address of the CloudLink virtual machine, and in the expanded **Inventory** pane, click the CloudLink virtual machine.

6. Click th&#x65;**&#x20;Launch Virtual Machine Console** button.

   ![](/images/vos360/2ecc1bb8d674914ed4784b8f.png)

7. From the virtual machine console, click anywhere on the console screen and press the **Tab** key until the orange highlight moves to the **Login** field.

8. In the **Login** field, type your Harmonic ID and then press **Tab**.

9. In the **Password** field, type your Harmonic ID password, press **Tab** and then **Enter**.

10. Do one of the following:

    * If the CloudLink has already been registered with a VOS360, begin working with Terminal UI.

    * If the CloudLink has not been registered, press the **Tab** key until you have selected the VOS360 you want to associate with the CloudLink. Press **Enter**.

11. When you are finished, click the **Close** button.
