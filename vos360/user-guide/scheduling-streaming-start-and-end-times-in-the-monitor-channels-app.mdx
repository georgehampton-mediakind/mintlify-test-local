You can schedule or manually start & stop streaming by muting the service output.

<Note>
  **Note:&#x20;**&#x53;cheduling streaming start and end times is applicable only under the following criteria:

  * OTT transcoding with HLS or ATS output

  * IPTV transcoding with IP or SRT Caller Mode output
</Note>

## Turn on the Mute Operation toggle under the Operator Action add-on

Before scheduling streaming start and end times, proceed with the following:

1. Navigate to the **Configure Channels** app > **Service&#x20;**&#x74;ab.

2. Enable the **Add-ons&#x20;**&#x63;heckbox.

3. Turn "On" the **Mute Operation&#x20;**&#x74;oggle under the **Operator Action&#x20;**&#x61;dd-on.

   ![image-20250915-043451.png](/images/vos360/23e7bb07ff398354b9d35f1b.png)

## Manual Start & Stop Streaming

1. Navigate to the **Monitor Channels&#x20;**&#x61;pp to check the following settings. \
   **Note**: This setting appears only when the **Mute Operation&#x20;**&#x74;oggle under the **Operator Action&#x20;**&#x61;dd-on is turned on from the service add-on.

   ![image-20250915-043736.png](/images/vos360/ebb28bd44684d91c57cbb75a.png)

   * **Off-air (Muted)** button: the output streaming will be stopped.

   * **On-air (Unmuted)** button: the output streaming will be started.

2. After clicking the **Save&#x20;**&#x62;utton, a pop-up window will appear to request confirmation.

   ![image-20250915-043851.png](/images/vos360/083ba78857e03f227310f139.png)

3. After clicking the "Off-air" or "On-air" button and saving the setting, the scheduled time will be unset, meaning the scheduled start/stop streaming tasks will be canceled.

## Schedule Start & Stop Streaming

1. Navigate to the **Monitor Channel&#x20;**&#x61;pp and check the following settings.

   **Note**: This setting appears only when the **Mute Operation&#x20;**&#x74;oggle under the **Operator Action&#x20;**&#x61;dd-on is turned on from the service add-on.

   ![image-20250915-045448.png](/images/vos360/a2378480db669625353bdfa3.png)

   * **Cross** button: Unsets the "Off-air" or "On-air" time.

   * **Calendar&#x20;**&#x62;utton: Opens a calendar for users to set the "On-air" and "Off-air" times.

2. &#x20;The start and end times set in the UI will be converted to the system wall clock time of VOS. There is no need to manually set the times to match the VOS system time.

   ![image-20250915-045524.png](/images/vos360/2b31e595262cde24bd3e9b6d.png)

3. After clicking the **Save&#x20;**&#x62;utton upon setting the "On-air" and "Off-air" times, the bar will display the current status (On-air or Off-air) and indicate when the streaming will start or stop.

   ![image-20250915-045551.png](/images/vos360/10609dde3ff85dd1ff84374c.png)
