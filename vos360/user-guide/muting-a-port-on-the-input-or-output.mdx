---
title: Muting a port on the input or output
robots: noindex, nofollow
---

You can turn each SRT/RTMP listening port on or off independently in real time. This allows you to trigger downstream input redundancy and monitor the source quality.

To mute or unmute an input or output, do the following:

1. Navigate to the **Syndicate** app.

2. Hover over the input or output you want to mute, and click the **Mute Port** button (![](/images/vos360/cf0c1b747408d96d665b9f27.png)).\
   A new window appears.

3. Toggle the **ON/MUTE** option to unmute or mute the input or output.\
   ![](/images/vos360/ddb7e516daef5c00c830e7e5.png)

4. Click **Update**.

   <Note>
     **Note:&#x20;**&#x49;f your container is an older version that does note support the Mute feature, a warning message displays and the ON/MUTE toggle buttons are disabled.
   </Note>

   <Note>
     **Note:&#x20;**&#x4D;uted states do not carry over if a container is restarted or turned offline. All input and output ports are unmuted when resumed.
   </Note>
