The Profiles panel displays important details about the profile and provides access to the Profiles editor.

![vos\_new\_lab\_wizard\_main\_v2.png](/images/vos360/001d59b08ff6fb1b17d2eae8.png)

From the Profiles panel, you can:

* Use the search bar to find profiles.

* Use the profile type filter to sort profiles. Click the **Show only Live Events** option to display only live event profiles.

* Use the profiles list to view key details about your profiles, including:

  * **Name**: The profile name. Click the column heading to sort the list alphabetically by name.

  * **Type**: The profile type. Click the column heading to sort the list alphabetically by profile type.

  * **Version**: The profile version.

  * **Services**: The number of services using the profile. Click the column heading to sort the list by this number.

  * **Comment**: Comments about the profile.

  * **Last Modified**: The date the profile was last modified. Click the column heading to sort the list by date.

  * **Actions:** Click the gear icon to see these actions:

    * **Open profile:** Select to view the profile in the Profile Panel.

    * **Delete profile:** Select to delete the profile.

    * **View services:** Select to see a list of services using the selected profile.

* At the top right of the screen, click ![lab\_wizard\_v1\_button.png](/images/vos360/190349a5a19831b31e6a62b9.png) to change the Profiles editor to the legacy Profile editor (LabWizard v1).
