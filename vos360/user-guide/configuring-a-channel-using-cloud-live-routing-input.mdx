---
title: Configuring a channel using Cloud (Live Routing) input
robots: noindex, nofollow
---

You can use either Cloud Source or Cloud Edge via Live Routing Service (LRS) as source input to create a channel.

1. From the **Channels** app, click **+ Channels**.

   ![](/images/vos360/7692ca28e452d2f2bc38d40a.png)

2. Enter the **Channel Name**.

3. Toggle the **Event Channel** to eithe&#x72;**&#x20;On** or **Off**.

4. Select the desired **Transcoding Profile** for the channel through the drop-down menu.

5. Set the **Time Shift Window** by dragging the button to the desired time-shift duration.\
   Note that the configured time-shift duration cannot be changed after the channel is created.

6. Configure the toggles as desired.

   * **DRM**: If the channel needs to be encrypted, enable the **DRM&#x20;**&#x74;oggle and configure the following:

     * Internal ID: Specify the DRM System.

     * DASH ID: Specify the Content ID or Resource ID for the DASH package.

     * HLS ID: Specify the Content ID or Resource ID for the HLS package.

   * **Logo:&#x20;**&#x49;f the channel supports logo insertion, enable the **Logo** toggle and follow the instructions [here](https://confluence360.harmonicinc.com/display/VOS360DOC/.Adding+a+logo+to+a+channel+v1.19).

   * **Graphics**: If the channel supports graphic templates, enable the **Graphics** toggle and configure the following:

     * Template: Select a graphics template file from the VOS file system.

     * RSS URL: You can configure VOS to fetch text field data from an RSS feed.

   * **Geo-Blocking**: If a channel needs to be blocked in specific geographical locations, enable the **Geo-Blocking** toggle and configure the following:

     * Allow/Block: Select the geographical location to be allowed or blocked.

     * Whitelisted IP Address: If a geographical location is selected as "Block," you can specify IP addresses to be whitelisted.

   * **Blackout Slate**: If the channel supports SCTE-35 blackout slate, enable the **Blackout Slate** toggle and configure the following:

     * Image: Configure the desired slate image for blackout purposes.

   * **Geo-Redundancy**: The geo-redundancy feature is only available when the Active Redundancy settings are enabled for the VOS360 instances for redundancy purposes. Contact Harmonic Support to have this feature activated.

7. If you want to filter by the user-defined labels, enter a label in the **Labels** field.\
   For more information, see [Adding labels to a service for generating usage breakdown details in the Harmonic Hub](/vos360/user-guide/adding-labels-to-a-service-for-generating-usage-breakdown-details-in-the-harmonic-hub).

8. Configure **Inputs**.

   * **Input Method**: Select Cloud (Live Routing).

   * **Source Channel**: Select your source channel. \
     Once a channel is selected, the Endpoint area displays any information on the Cloud Source or Cloud Edge associated with the channel. More information is available in the [Syndicate app overview](/vos360/user-guide/syndicate-app-overview).

     <Note>
       **Note:** Multiple Cloud Edges can connect to the same Cloud Source to pull the same channel. If the Cloud Source endpoint is created in the same region with the VOS360 deployment, the endpoint will be available when adding a channel with the Cloud (Live Routing) input. More information is available in the [Syndicate app overview](https://confluence360.harmonicinc.com/display/VOS360DOC/.Syndicate+app+overview+v1.17.0).
     </Note>

   * **Input Loss:&#x20;**&#x59;ou can specify an image for the circumstance of input signal loss.

   * **+** **button**: Click this to add a secondary source channel. Select your secondary source from the **Source Channel** pulldown menu. \
     When the secondary source option is enabled, the **Input Redundancy** toggle appears on the left. Click the toggle and choose from the following:

     * **Global**: Input source redundancy is triggered when video PID is missing or the video source is non-decodable.

     * **Custom**: Choose this option to overwrite the Global configuration. The options are as follows:

       * **Video Missing**: When enabled, input source redundancy is triggered when video PID is missing or the source is non-decodable.

       * **Audio PID Missing**: When enabled, input source redundancy is triggered when audio PID is missing.

       * **Scrambled Video PID**: When enabled, input source redundancy is triggered when one or more video packets are scrambled in the primary input source. This option is consistent with Audio PID Missing.

       * **Continuity Counter Error**: When enabled, input source redundancy is triggered when the number of CC errors exceeds the specific threshold.

   * **Endpoint**: Select either Cloud Source or Cloud Edge as the endpoint of source input. Use the pulldown menu to select the Cloud Edge endpoint.

     <Note>
       **Note:** The endpoints are only displayed in the menu when the endpoints are set up in the same region as the VOS360 deployment.
     </Note>

     If you have access to the Syndicate app, click ![](/images/vos360/c12ce3eeab2884f454a4cbce.png) to open the app in a new tab.

9. Click **Connect&#x20;**&#x74;o groom the source input.

10. Select your **Streaming Protocol** from the lower menu.

11. (Optional). Click the **Online**/**Offline** buttons to set the channel online/offline after it is created.

12. Click **Create Channel**.
