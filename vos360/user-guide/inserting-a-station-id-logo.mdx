title: Inserting a Station ID (logo)
robots: noindex, nofollow
---

A Station Id corresponds to a logo that is inserted on the video.

From the **Configure Broadcast** app, at multiplexer level, do the following:

<Note>
  **Note:&#x20;**&#x54;his logo add-on is also applied to the service level.
</Note>

1. Click the **Edit&#x20;**&#x62;utton of the program.

2. Select the **Transcoding&#x20;**&#x74;ab.

3. From the Logo add-on, click **Configure** and the **Edit&#x20;**&#x69;con to select the image file for logo insertion.\
   ![](/images/vos360/9c4a65d43c8cc1f4b72f0ef4.png)

4. From the **Upload by URL&#x20;**&#x74;ab, you can use an HTTP server URL to download the PNG image files.\
   ![](/images/vos360/f8282299d68adf5673e4a8c6.png)

5. Set the **Path** to download the picture.

6. Define a **Label** to identify easily the picture.

7. From the **File Uploader** tab, you can drag and drop your file for uploading to VOS which allows the PNG files to download with local storage (no need for an external HTTP server). \
   ![](/images/vos360/17f391f243f3de5b293d6892.png)

8. Click **Save**.

9. Set the **Offset** of the image.

10. If it's not a permanent logo, set the **Hourly Schedule**. Up to two schedules can be added.

11. Click **Save**, and the Logo becomes **ON**.

12. After a few seconds, the logo appears on the thumbnail of the video.\
    ![](/images/vos360/90d3812a92c303c9261cb51c.png)

<Warning>
  **Warning!**

  You can only use .png files, and size of the logo must be smaller than the size of the video.
</Warning>
