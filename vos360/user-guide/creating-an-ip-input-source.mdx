From the **Configure Broadcast** app, click ***+Source&#x20;***&#x61;nd select **IP&#x20;**&#x74;o create an IP source **with proxy**:

![](/images/vos360/d0fe82355cc207c2b83577ef.png)

## **Settings tab**

**Source information**:

* Define an input source name that will appear on the Configure Broadcast view.

* Configure the standard for the type of signaling in the source: DVB or ATSC.

  <Note>
    **Note:&#x20;**&#x53;electing ATSC enables incoming PSIP analysis. Major channel and minor channel numbers are displayed and PSIP EIT remultiplexing is then possible.
  </Note>

* Define the maximum number of programs authorized from this input.

**Input**:

* Set the network IP parameters that allow the VOS to retrieve the IP source and its associated programs.

* (Optional) Set High Jitter to **ON**.

* Set the Sync Loss Detection Threshold (Default is 0.2 seconds)

* If Redundancy is used for the source, set the network IP parameters that allow the VOS to retrieve the backup IP source.

  * Configure the Redundancy Mode with the possible values: "Auto/Revert on Backup Failure" (default), and "Manual".

  * Set the Failover Settings:

    * Global - Default settings are defined in Configure Channel → Settings → Advanced

    * Custom - Continuity Counter Error and Scrambled Video PID can be selected

* If ST 2022-7 is used for the source, set the network IP parameters to perform hitless input redundancy with TS over IP inputs based on ST 2022-7.

  <Note>
    **Note:&#x20;**&#x59;ou can enter any valid Path Differential value in the range of 50 ms to 450 ms. The 50 ms value is the default.
  </Note>

Click **+Create**, the source appears on the left panel:

![](/images/vos360/8c7879852a3324737bd6ae2e.png)
