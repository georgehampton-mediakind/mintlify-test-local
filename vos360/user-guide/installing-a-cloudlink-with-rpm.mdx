## Prerequisites

* Host with the following or better hardware configuration:

  * 4 CPU

  * 32 GB memory

  * 200 GB free storage

* CentOS 7.4 (1708) minimal install

* Networking:

  * SSH access to the host

  * Internet access from the host

* Firewall:

  * The following firewall rules are configured on the host on CloudLink start by default.

    ```text
    iptables -A INPUT -i lo -j ACCEPT                                  # Allow all traffic from localhost
    iptables -A INPUT -s 127.0.0.1-j ACCEPT                           # Ditto
    iptables -A INPUT -m state --state ESTABLISHED,RELATED -j ACCEPT   # Allow any established connections
    iptables -A INPUT -p tcp --dport 22-j ACCEPT                      # Allow SSH
    iptables -A INPUT -p udp -j ACCEPT                                 # Allow stream traffic
    iptables -P INPUT DROP                                             # Drop other traffic
    ip6tables -P INPUT DROP
    ```

    <Note>
      **Note:** Your network should be pre-configured on the host. No additional network configuration is needed on CloudLink application.
    </Note>

1. Configure the management and multicast interface on the host. You can configure the interface in /etc/sysconfig/network-scripts.

2. Make sure you have received the .rpm file from Harmonic.

3. Upload the RPM to the target host.

4. Deploy CloudLink with RPM by entering the following command:

   ```text
   sudo rpm -ivh vos-cloudlink.rpm
   ```

5. Enter the following command to start CloudLink. It might take 5 minutes to initialize the CloudLink application.

   ```text
   sudo vosctl start
   ```

6. Access Cloudlink by entering the following command:

   ```text
   sudo vosctl sh
   ```
