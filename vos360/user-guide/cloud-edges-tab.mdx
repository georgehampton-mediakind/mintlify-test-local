You can create and monitor cloud edges through the Cloud Edges tab in the Syndicate app.

![](/images/vos360/6f81f51d8a5e1a3146ded7e1.png)

The tab displays the following:

* **Cloud edge search bar**: Enter the name of the cloud edge you want to search for.

* **Active cloud edges**: Monitor any active cloud edge.

* **Cloud edge creation button**: Click the button to create a cloud edge.

The following pages describe how to create, update, delete, and monitor Cloud Edges:

* [Creating a Cloud Edge](/vos360/user-guide/creating-a-cloud-edge)

* [Updating a Cloud Edge](/vos360/user-guide/updating-a-cloud-edge)

* [Deleting a Cloud Edge](/vos360/user-guide/deleting-a-cloud-edge)

* [Monitoring a Cloud Edge](/vos360/user-guide/monitoring-a-cloud-edge)
