---
title: Configuring a Cloud input without demux
robots: noindex, nofollow
---

1. From the **Configure Broadcast** app, click **+Source&#x20;**&#x61;nd select **Cloud**.

   ![vos\_add\_source\_cloud\_no\_demux.png](/images/vos360/cc47f4caed2feca5d65272c7.png)

2. In the **Input Source Name** field, enter the name of the new source.

3. If you wish to be able to filter by user-defined labels, enter a label in the **Labels** field.

4. Select the desired **Source Channel.**

5. If the Source Channel is shared, select the **Stream ID**.

6. Use the toggle to set the **Automatic Grooming** to **On** or **Off**.\
   **Note:** If set to **Off**, click **Connect** to groom the source.

7. In the **Endpoint** area, select **Cloud Edge**.

8. Select your desired **Edge Channel**.

9. Enter the **Latency&#x20;**&#x69;n miliseconds.\
   **Note:** The latency entered must be greater than or equal to the recommended latency.

10. If needed, click the **+** next to the Primary Cloud tab to add a Second Cloud, and repeat these instructions.

11. If needed, click the **+** next to the Second Cloud tab to add a signal loss image. See [Configuring a signal loss image](/vos360/user-guide/configuring-the-signal-loss-input) for more information.

12. Click **Create**.
