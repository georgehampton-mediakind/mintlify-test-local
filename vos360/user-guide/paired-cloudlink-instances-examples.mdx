Examples of CloudLink instances before and after pairing are available in the Configure Channels app and Terminal UI.

**Paired CloudLink instances in the Configure Channels App**

* Before CloudLink instances are paired:

  * Both are displayed.

* After CloudLink instances are paired:

  * The new instance is no longer displayed.

  * The label on the existing one changes to Redundant, indicating a CloudLink pair.

**Paired CloudLink instances in Terminal UI (OVA installation only)**

* Before CloudLink instances are paired:

  * &#x20;The new one uses the default Docker container name.

  * The existing one uses the name you gave it.

* After CloudLink instances are paired:

  * &#x20;The new one is given the name of the existing one, plus the characters **–B**\
    **Example:&#x20;**&#x43;L-WS2 + **-B**

  * The characters **-A** are appended to the name of the existing CloudLink (CL-WS2 + -A)\
    **Example**: CL-WS2 + **-A**
