## Thumbnail package parameters

The thumbnail packaging format is a standalone packaging type that can be used jointly with other packaging outputs by players, in order to offer content preview functionality to end-users for seeking. This allows players to display "visual cues" in the scrub bar and also to offer a kind of trick mode fully based on a web app (avoiding decoding video frames using an actual video player).

A thumbnail package is independent of existing OTT packaging formats for it to be sharable for multiple OTT package outputs with pull packaging. The thumbnails can be grouped as image sprites for static applications (Catch-Up, Long-Lasting Catch-Up and VOD), in order to reduce the number of downloads.
