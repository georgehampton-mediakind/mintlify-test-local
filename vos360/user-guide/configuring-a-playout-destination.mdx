The playout service can have an IP, downlink CloudLink, or CDN destination.

**Before you begin**\
[Configuring a playout source](https://confluence360.video.harmonicinc.com/wiki/spaces/V1UGD/pages/469191331/Configuring+a+playout+source)

1. From the **Configure Channels** app, navigate to the **Destination&#x20;**&#x70;age. Click **+ Destination**.

2. In the **Destination Name** field, enter the name of the new destination.

3. Select the destination **Type** and **Profile**.

4. If you wish to be able to filter by user-defined labels, enter a label in the **Labels** field.

5. Configure a signal loss output by selecting an image from a file server, or remove the output by clicking **Remove Output**.

6. Click **+Output** and select the output type from the list.\
   Note that Origin/CDN destinations have a single output option.

7. Configure the settings for the type of output you are using.
