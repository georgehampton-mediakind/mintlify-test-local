Use the Terminal UI interface and commands to initiate a stream for testing purposes.

* Use the CloudLink Terminal User Interface (TUI) to initiate a test stream.

  * The CloudLink spools a test stream to the VOS360.

  * The test stream can be discovered as an input source.

  * The multicast socket is fixed on the CloudLink:

    * 224.1.1.1:12345

* Use the command `start stream` to initiate the test stream.
