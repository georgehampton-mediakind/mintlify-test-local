---
title: Creating a primary event
robots: noindex, nofollow
---

You can create file-based and live primary events by simple drag-and-drop from the **Assets** or **Feed** widget. You can also use the **New primary event** dialog to create file-based primary events.

Note that if you want to specify an audio grooming profile for a primary event, you must do so using the **New Primary Event** dialog.

1. Click the **Edit** slider button to activate Edit mode.

2. Create a primary event using one of the following methods:

   * Select a file-based video asset from the **Assets** widget, or select a live input from the **Feeds** widget, and then drag it to the **Events&#x20;**&#x74;able before the first event, between two events, or after the last event.\
     A new primary event is automatically inserted. To edit the event details, select the event on the **Events&#x20;**&#x74;able and click **Edit**.

   * On the **Events&#x20;**&#x74;able, select a primary event and click **Create event before** or **Create event after**.

     The **New Primary Event** dialog opens, where you may configure the primary event details.

4. When you are finished editing the playlist, click the **Edit** slider button to deactivate Edit mode.
