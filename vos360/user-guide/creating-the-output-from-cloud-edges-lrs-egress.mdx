---
title: Creating the output from cloud edges (LRS egress)
robots: noindex, nofollow
---

1. From the **Syndicate** app, click **+Cloud Edges**.

2. Enter the following:

   * Use the menu to choose the cloud source.

   * (Optional) Use the menu to select the backup cloud source.

   * Enter the cloud edge name.

   * Region. Make sure that this is the same region as the VOS360 cluster.

   * Source protocol: Choose **SRT**.

   * Encryption type. Choose from the following:

     * No Encryption

     * AES 128

     * AES 192

     * AES 256

3. Click **Create**.

   ![](/images/vos360/c5fc009b60912b83b3985502.png)

4. Click **Copy URL** under the Cloud Edge Egress Endpoint field. This URL is used when configuring the SRT output.

   ![](/images/vos360/eec2a434aadb5def7316c6c0.png)
