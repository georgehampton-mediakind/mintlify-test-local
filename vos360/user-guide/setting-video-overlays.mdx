You can insert video with some overlay as follows:

* Logo: for Station ID purposes. (Refer to the sub-section for details.)

* Graphics: crawl text or animated logo. (Refer to the sub-section for details.)

* Video Insertion: for blackout purposes (not described in this document).

* EAS-NET: video overlay can be performed according to the alert based on Station ID configured using the EAS-NET protocol.

* Blackout Slate: in case of signal loss.
