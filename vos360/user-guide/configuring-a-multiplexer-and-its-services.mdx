To create an MPTS output, use the **Configure Broadcast** app.

For ATSC multiplexers, if you use an external PSIP injector or fetch program guide data to build EIT/ETT, you may need to declare it first. (To do so, refer to [Customizing global settings](/vos360/user-guide/customizing-global-settings) for the PSIP details.)

![](/images/vos360/7c8d10bd7a74d590fafd6416.png)

The following MPTS profiles are available for the multiplexer:

* ATSC 1.0 (no PSIP) MPTS

* ATSC 1.0 (no PSIP) MPTS - first program is 3

* ATSC 1.0 MPTS

* ATSC 1.0 MPTS - first program is 3

* DVB MPTS

* DVB-SIS DSA

* DVB DTT MPTS

<Note>
  **Note:&#x20;**&#x54;he IP, SRT, and HSP/HLS input sources can be created directly from the **Configure Broadcast&#x20;**&#x61;pp.

  The input sources already created with the **Configure Channels** app, appear automatically in the Sources pane on the left.
</Note>
