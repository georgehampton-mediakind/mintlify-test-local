title: Configuring a channel using SRT input
robots: noindex, nofollow
---

You can use SRT as a source input to create a new channel.

1. From the **Channels** app, click **+ Channels**.

   ![](/images/vos360/1f4c760cefeb26ae48e207b1.png)

2. Enter the **Channel Name**.

3. Toggle the **Event Channel** to eithe&#x72;**&#x20;On** or **Off**.

4. Select the desired **Transcoding Profile** for the channel through the drop-down menu.

5. Set the **Time Shift Window** by dragging the button to the desired time-shift duration.\
   Note that the configured time-shift duration cannot be changed after the channel is created.

6. Configure the toggles as desired.

   * **DRM**: If the channel needs to be encrypted, enable the **DRM&#x20;**&#x74;oggle and configure the following:

     * Internal ID: Specify the DRM System.

     * DASH ID: Specify the Content ID or Resource ID for the DASH package.

     * HLS ID: Specify the Content ID or Resource ID for the HLS package.

   * **Logo:&#x20;**&#x49;f the channel supports logo insertion, enable the **Logo** toggle and follow the instructions [here](https://confluence360.harmonicinc.com/display/VOS360DOC/.Adding+a+logo+to+a+channel+v1.19).

   * **Graphics**: If the channel supports graphic templates, enable the **Graphics** toggle and configure the following:

     * Template: Select a graphics template file from the VOS file system.

     * RSS URL: You can configure VOS to fetch text field data from an RSS feed.

   * **Geo-Blocking**: If a channel needs to be blocked in specific geographical locations, enable the **Geo-Blocking** toggle and configure the following:

     * Allow/Block: Select the geographical location to be allowed or blocked.

     * Whitelisted IP Address: If a geographical location is selected as "Block", you can specify IP addresses to be whitelisted.

   * **Blackout Slate**: If the channel supports SCTE-35 blackout slate, enable the **Blackout Slate** toggle and configure the following:

     * Image: Configure the desired slate image for blackout purposes.

   * **Geo-Redundancy**: The geo-redundancy feature is only available when the Active Redundancy settings are enabled for the VOS360 instances for redundancy purposes. Contact Harmonic Support to have this feature activated.

7. If you wish to filter by the user-defined labels, enter a label in the **Labels** field.\
   For more information, see [Adding labels to a service for generating usage breakdown details in the Harmonic Hub](https://confluence360.video.harmonicinc.com/wiki/spaces/V1UGD/pages/469058709/Adding+labels+to+a+service+for+generating+usage+breakdown+details+in+the+Harmonic+Hub).

8. Configure **Inputs**.

   * **Input Method**: Select SRT.

   * **IP**: You can also specify the IP details for the source CloudLink input.

     * **IP Address**: Enter the source **IP Address**.

     * **Port**: Enter the source **Port** number.

     * **Decryption type:&#x20;**&#x43;hoose the decryption type.

     * **Connection Mode**: Choose either **Push** or **Pull**.

   * **Input Loss:&#x20;**&#x59;ou can specify an image for the circumstance of input signal loss.

9. Click **Connect** to groom the source input.

10. Select your **Streaming Protocol** from the lower menu.

11. (Optional). Click the **Online**/**Offline** buttons to set the channel online/offline after it is created.

12. Click **Create Channel**.
