From the Configure Channels app, filter using a variety of facets to help you quickly find the desired source, destination, or service.

**The filter drop-down**

The filter drop-down presents a list of facets based on the page you are viewing. You can filter sources by the following:

* State (**Used** or **Unused**)

* Input status (**Input defined** or **No input**)

You can filter destinations by the following:

* Type (**IP** or **Origin/CDN**)

* State (**Used** or **Unused**)

You can filter services by the following:

* Priority (**Low**, **Normal**, **High**)

* State (**Active** or **Inactive**)

* Type (**IPTV**)

* Scrambling (**Enabled**, **Disabled**)
