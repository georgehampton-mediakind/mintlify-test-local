---
title: Adding unreferenced PIDs to the transcoded or passthrough output programs
robots: noindex, nofollow
---

The Configure Broadcast app allows the ingestion of data PID that comes as an unreferenced PID. The unreferenced PID can be re-multiplexed as a data component of an output transcoded or passthrough program. The generated output data PID is referenced in a service.

1. Navigate to the **Configure Broadcast** app.

2. Create a data component by clicking the "**+**" button on the output program.\
   ![](/images/vos360/e2220dbdf603a07f233db2ef.png)

<Note>
  **Info:** If the "**+**" button is not displayed, click the ![](/images/vos360/f175f03f9e1e0581ef191b85.png)button at the top right to edit the Multiplexer settings and configure the **Unreferenced PIDs/Local Programs** checkbox.
</Note>

3. From the **Source&#x20;**&#x74;ab, do the following:

   ![](/images/vos360/0763e3cb41cd0c37fd339ddb.png)

   1. Select the input **Source**.

   2. Set the input **Component PID&#x20;**&#x6E;umber.

4. From the **Remapping&#x20;**&#x74;ab, do the following:

   ![](/images/vos360/1d0de022727198c8509e0b61.png)

   1. Set the output **Component PID&#x20;**&#x6E;umber.

   2. Select the **Stream Type**.

5. From the **PMT descriptors** tab, add the PMT descriptors on the component level.\
   ![](/images/vos360/5765ae729d66d6bb3ea5e771.png)

6. Click **+Add.**
