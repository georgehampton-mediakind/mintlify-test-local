---
title: Monitoring a Cloud Source
robots: noindex, nofollow
---

By default, the list of Cloud Sources does not show any monitoring information.

To monitor a Cloud Source, do the following:

1. Navigate to the **Syndicate&#x20;**&#x61;pp.

2. Click **Bitrate/Distribution** on the tile of the channel you want to monitor to activate display monitoring.

3. The Bitrate tab displays the following:

   * Packet Received.

   * Packet Lost.

   * Input bitrate graph.

4. The Distribution tab displays the following:

   * A list of Cloud Edges connecting to this Cloud Source.

5. Once your monitoring is complete, click **Bitrate/Distribution** again to de-activate it. This prevents the UI from overloading.
