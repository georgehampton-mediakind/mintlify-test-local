Configure a destination for mux services with the destination type configured as MPTS.

<Note>
  **Important!**

  If you create and configure the mux service using the Configure Broadcast app, the mux destination is automatically created in the Configure Channel app. Refer to [Adding and configuring a multiplexer](/vos360/user-guide/adding-and-configuring-a-multiplexer) for details.
</Note>

**Before you begin**\
[Configuring a source input](/vos360/user-guide/configuring-a-source-input)

1. From the **Configure Channels** app, navigate to the **Destinations** page, click **+ Destination**.

   ![](/images/vos360/e266b924fecabae2d3dc277f.png)

2. For **Destination Name**, type the name of the mux destination.

3. For **Type**, select **MPTS**.\
   The default output type **IP&#x20;**&#x69;s selected under **Outputs**.

4. Verify that the selected **Profile** is a mux profile.

5. Optionally, in the **Labels** field, enter a label associated with the destination.

   <Note>
     **Info:&#x20;**&#x4C;abels can help you search and find destinations more quickly.
   </Note>

6. If you wish to use an output that is different from the default, click **Remove output** and then click **+Output** and select the desired output type from the list.\
   The mux destinations use IP, Cloudlink, or Relay (HSP) outputs.

7. Enter the multicast IP address and port number for the egress output streams.

8. For mux output with a **CloudLink&#x20;**&#x64;estination, enter the name of the downlink CloudLink.

9. For mux output with **SRT** destination, use the default SRT settings or configure the custom SRT settings:

10. For mux output with **Cloud (Live** **Routing)** destination, the Cloud channel will be available as a source to be up-linked to the Harmonic's Cloud via Live Routing Service. This configuration requires access to the Syndicate app.

11. For mux output with **Relay (HSP)** destination, no custom configurations are required.

12. If the service will be encrypted and you want to be able to monitor clean video output, select **Output Monitor** and provide the delivery **IP address** and **Port** for monitoring.

13. Click **Create**.
