Video slate insertion is supported as a signal loss slate type by taking a pre-configured WebM video file.

**Pre-requisites**

Prepare a WebM video file for slate insertion. The WebM file should have the same resolution and framerate as the service output (the highest output for OTT service).

1. Navigate to **Asset Acquisition&#x20;**&#x61;pp > **Incoming&#x20;**&#x74;ab, and upload the WebM video file using the Web Uploader.

   ![](/images/vos360/09189d72b7f4007d6a288a87.png)

2. Navigate to **Asset Acquisition&#x20;**> **Graphics&#x20;**&#x74;o view the assets that have been uploaded.\
   ![](/images/vos360/442be6ba541915bea6cc0ba1.png)

3. Navigate to **Configure Channels** app > **Sources** tab > **Inputs**.

4. Enable the **Display a Video Slate** toggle.\
   ![](/images/vos360/18e09c2abac73409fa8a9ef3.png)

5. Select the WebM file by clicking the pencil icon.\
   ![](/images/vos360/783fb1b9f2f2a854793f19ca.png)

6. Select the desired WebM file from the popup window. Click the **Save&#x20;**&#x62;utton after the selection.\
   ![](/images/vos360/68ec46385aca7fb9c3598e47.png)

7. Save the source if ready.
