Use the Channels app and VMware vSphere Client to manage CloudLink instances.

* Register and pair CloudLink instances.

* Remove instances from a VOS360.

* Rename CloudLink instances.

* Users must have access to the Channels app

Channels app\
![](/images/vos360/5ae3f2117c645a8ec87e68ec.png)
------------------------------------------------

## VMware vSphere Client

* Launch a virtual machine console running Terminal UI.

* Associate the CloudLink with a VOS360.

* Configure CloudLink networking.

* Users must have the console interaction permission\
  ![](/images/vos360/1c73c7dcbc4943da8c10a849.png)
