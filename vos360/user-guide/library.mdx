Video assets appear in the **Library** once transcoding or grooming is completed.

<Note>
  **Info:&#x20;**&#x46;ile-based assets extracted from a Playout Channel also appear in the Asset Acquisition **Library**.
</Note>

## Searching an asset

The search bar allows to filter the asset by:

* Title name

* Labels

The search is not case sensitive. The whitespace works as *OR*.

## Asset labels

The labels can used for tagging assets for usage reports and also for asset filtering by API. Some labels are assigned automatically by the Asset Acquisition applications, users can add custom labels and all labels can be updated.

<Note>
  Some automatically assigned labels like frameRate and frameSize are used by Playout application. It is recommended to avoid doing any changes to them.
</Note>

![image-20260204-183352.png](/images/vos360/53913dd89a0955117ef2ee7f.png)

## Removing an asset file from the library

### Removing an asset file

You can remove an asset file from the library permanently by selecting the desired asset Titles above the thumbnail.

1. Select the Title checkbox above the thumbnail for the asset.

2. Select **Titles** from the **Delete selected** drop-down list.

3. Click **Delete** to confirm. The entire Asset is deleted, including info, transcoded files, and source files, if any.

   ![](/images/vos360/c66ffa581a1d0b3fdffda79d.png)

<Note>
  **Note:&#x20;**&#x4F;nly up to 5 titles can be selected for a deletion from UI. Please use public REST API to delete larger amounts of assets.
</Note>

### Deleting a source file

You can delete a source file only from the library by selecting the desired asset titles above the thumbnail.

1. Select the Title checkbox above the thumbnail for the asset.

2. Select **Source files only&#x20;**&#x66;rom the **Delete selected** drop-down list.

3. Click **Delete** to confirm.

<Note>
  **Info:&#x20;**&#x44;eleting source files helps to free up space and reduce the storage costs. Please make sure to delete the source files only after all desired transcoding is completed. It is not possible to transcode an asset to new profiles after its source is deleted.
</Note>
