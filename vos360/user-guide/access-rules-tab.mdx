To better secure the LRS endpoints from unsolicited input, you can use the Access Rules tab to setup a whitelist of IP addresses affiliated with their sources so that the LRS inputs can accept the input.

To create an Access Rule, do the following:

1. Navigate to the **Syndicate** app.

2. Click the **Access Rules** tab.

3. Click **+Access Rule**.

   ![vos\_create\_access\_rule.png](/images/vos360/6cde191c9a44035d32436c5b.png)

4. Enter the following:

   1. **Access Rule name:** Enter a name for your access rule.

   2. **Description:** Enter an optional description for the access rule.

   3. **Cloud subscription account location mapping:** Click the pulldown to select the account mapping.

   4. **Platform:** Click the pulldown to select the LRS platform type.

   5. **Region:** After selecting a platform, click the pulldown to select the LRS region.

   6. **Type:** Click the pulldown to select either Cloud Source or Cloud Edge.

   7. **Input allow list:** Enter any IP addresses you want to provide access to.\
      **Note:** This option is only available for Cloud Sources.

   8. **Output deny list:** Enter any IP addresses you want to block from connecting to your instance.

   9. **Labels:** Enter an optional label for the access rule.

5. Click **Save**.
