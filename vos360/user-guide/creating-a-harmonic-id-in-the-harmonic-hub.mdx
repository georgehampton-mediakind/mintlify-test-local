Harmonic IDs are created in the Harmonic Hub and then imported into a VOS360.

<Note>
  **Info:&#x20;**&#x4F;nly those users with the role of Harmonic Hub Admin may create and delete Harmonic IDs.
</Note>

<Note>
  **Info:&#x20;**&#x54;he Harmonic ID must use a corporate email address, and cannot use a public-domain address (gmail, yahoo, etc.).
</Note>

1. From the Harmonic Hub, click the **Harmonic ID** tab.

2. Click the **Add user** icon to open the **Add a new user** page.

   ![](/images/vos360/e1351b2713288d337842b7f1.png)

3. Enter the new user **Email Address** and select a user **Role**.

4. Grant permissions to the **Role** as desired:

   * **Admin** role: Select this option to grant appropriate permissions to **SaaS Admin** in VOS360 (The Harmonic ID Administration checkbox needs to be enabled).

   * **Normal** role: Select this option to grant appropriate permissions to **SaaS Role** in VOS360 (The Harmonic ID Administration checkbox needs to be disabled).

   * **Support Partner** role: Select this option to grant appropriate permissions to **Support Partner** (The Harmonic ID Administration checkbox needs to be disabled).

5. Click **Create**.\
   **Result**: The Harmonic ID is added to the VOS corporate account, and can be imported to any VOS360 associated with that account.
