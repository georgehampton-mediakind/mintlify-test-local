title: Managing users and roles
robots: noindex, nofollow
---

VOS360 super admins can manage the user accounts and roles that are associated with a particular VOS360.

Each user requires a Harmonic ID which is the credential used to log in to the Harmonic system. From the Harmonic Hub, you can create a Harmonic ID and grant appropriate permissions to a user.
