The following components make up the VOS360 service:

* **VOS360 applications**: \
  The VOS360 software applications and the underlying cloud and delivery infrastructure (provided, managed and operated by Harmonic).

* **Live Routing Service:**\
  LRS provides a global reach video router in the cloud through a combination of public internet and the cloud provider's inter-regional network.

* **CloudLinks**: \
  One or more CloudLink instances, for delivery of live media content to and from a cloud.

* **Harmonic Hub**: \
  The Harmonic Hub, a cloud-based SaaS that serves as the online administration console for connecting with Harmonic support, configuring profiles and user rights, administrating account preferences, retrieving usage data etc.

<Note>
  **Info:&#x20;**&#x43;loudLink reaches end of support life by the end of 2027. If you use CloudLink to ingest live sources from on-premises to the cloud, consider replacing it with the XOS appliance.
</Note>
