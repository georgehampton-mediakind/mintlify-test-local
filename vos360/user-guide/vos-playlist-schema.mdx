VOS supports XML playlist files based on the Polaris Play: Playlist Control (OPC) playlist schema. BXF playlist files are also supported.

&#x20;*Figure: Sample XML playlist*  \
&#x20;![](/images/vos360/caf4c853e2786d0658a5d1ff.png)

## \<PrimaryEvent> parameters

<div className="vos-table-scroll">
  <table className="vos-source-table">
    <colgroup span="1"><col span="1" /><col span="1" /></colgroup>

    <tbody><tr><td colSpan="1" rowSpan="1"><p>startMode</p></td><td colSpan="1" rowSpan="1"><p>Determines how the event will be taken to air:</p><ul><li><p>fixed: Event is taken to air at its scheduled start date/time.</p></li><li><p>follow: Event is taken to air when the current on-air event ends.</p></li><li><p>manual: Requires a <strong>Take Next</strong> trigger to take the event to air.</p></li></ul></td></tr><tr><td colSpan="1" rowSpan="1"><p>scheduledStart</p></td><td colSpan="1" rowSpan="1"><p>Determines when fixed start events are taken.</p></td></tr><tr><td colSpan="1" rowSpan="1"><p>endMode</p></td><td colSpan="1" rowSpan="1"><p>Determines how the event is terminated:</p><ul><li><p>duration: The event ends when the scheduled duration expires. A primary event with duration end mode can be preempted by an upcoming fixed start event.</p></li><li><p>manual: The event remains on-air until a <strong>Take Next</strong> command is received from the operator, or it is preempted by an upcoming fixed start event.</p></li></ul></td></tr><tr><td colSpan="1" rowSpan="1"><p>scheduledDuration</p></td><td colSpan="1" rowSpan="1"><p>Determines the length of time that a primary event stays on-air. For manual endMode events, the duration does not end the event.</p></td></tr></tbody>
  </table>
</div>

## &#x20;\<VideoMaterial> parameters

<div className="vos-table-scroll">
  <table className="vos-source-table">
    <colgroup span="1"><col span="1" /><col span="1" /></colgroup>

    <tbody><tr><td colSpan="1" rowSpan="1"><p>materialId</p></td><td colSpan="1" rowSpan="1"><ul><li><p>For file-based assets:</p><ul><li><p>If the asset is already registered in Asset Acquisition library, you can provide either the file name or the file name with extension.</p></li><li><p>If the asset ingest shall be triggered on playlist reception, then you must provide the full S3 URL.</p></li></ul></li><li><p>For a live primary event generated by an external input, provide the CloudLink input source name.</p></li></ul></td></tr><tr><td colSpan="1" rowSpan="1"><p>source</p></td><td colSpan="1" rowSpan="1"><p>For a live primary event, you must set the source to External In. For file-based events, you may omit the source parameter, or set it to Player A.</p></td></tr><tr><td colSpan="1" rowSpan="1"><p>som</p></td><td colSpan="1" rowSpan="1"><p>Specify the Start of Material (SOM) in one of two ways:</p><ul><li><p>As a frame offset from the beginning of the file, for example +00:00:59;28</p></li><li><p>As the timecode value of the frame at which playback will begin, for example 05:02:23:21 (not to be expressed in milliseconds)</p></li></ul></td></tr><tr><td colSpan="1" rowSpan="1"><p>audioProfile</p></td><td colSpan="1" rowSpan="1"><p>(MXF files with PCM audio only) Specify the audio grooming profile to be used for the primary event. Audio grooming profiles are configured in the Asset Acquisition app. Refer to <a href="/vos360/user-guide/creating-an-audio-grooming-profile-for-mxf-files">Creating an audio grooming profile for MXF files</a> for more information.</p><blockquote><p><strong>Info:</strong> The languages specified in the grooming profile must match the languages defined for the playout source. </p></blockquote><blockquote><p><strong>Note: </strong>For .mp4 files, it is not possible to specify an audio grooming profile. For the first audio, the first stereo pair is played. For the second audio, the second stereo pair is played, and so on.</p></blockquote></td></tr><tr><td colSpan="1" rowSpan="1"><p>title</p></td><td colSpan="1" rowSpan="1"><p>Optionally, provide a title for the event.</p></td></tr></tbody>
  </table>
</div>

## &#x20;\<GraphicsEvent> parameters

<div className="vos-table-scroll">
  <table className="vos-source-table">
    <colgroup span="1"><col span="1" /><col span="1" /></colgroup>

    <tbody><tr><td colSpan="1" rowSpan="1"><p>templateName</p></td><td colSpan="1" rowSpan="1"><p>Provide the graphic template file name.</p></td></tr><tr><td colSpan="1" rowSpan="1"><p>layer</p></td><td colSpan="1" rowSpan="1"><p>Specify the layer that the graphic template will be loaded on. Up to 8 layers are supported.</p></td></tr><tr><td colSpan="1" rowSpan="1"><p>startMode</p></td><td colSpan="1" rowSpan="1"><p>The timing of the start of a secondary event is determined by an offset from the start or end of the primary event to which it is attached (specified in startOffset). There are two secondary event start modes:</p><ul><li><p>offsetFromStart: The secondary event will go to air at a time relative to the start of its primary event. Negative values are used to specify that the secondary event is scheduled to start before the start of the primary event, and positive values are used to specify that the secondary event is scheduled to start after the start of the primary event.</p></li><li><p>offsetFromEnd: The secondary event will go to air at a time relative to the end of its primary event. Negative values are used to specify that the secondary event is scheduled to start before the end of the primary event, and positive values used to specify that the secondary event is scheduled to start after the end of the primary event.</p></li></ul></td></tr><tr><td colSpan="1" rowSpan="1"><p>endMode</p></td><td colSpan="1" rowSpan="1"><ul><li><p>offsetFromEnd: The secondary event will end at a time offset relative to the end of its primary event (specified in endOffset). Negative values are used to specify that the secondary event is scheduled to end before the end of the primary event, and positive values used to specify that the secondary event is scheduled to end after the end of the primary event.</p></li><li><p>duration: The secondary event will end after the time specified in the duration parameter.</p></li></ul></td></tr><tr><td colSpan="1" rowSpan="1"><p>title</p></td><td colSpan="1" rowSpan="1"><p>Optionally, provide a title for the event.</p></td></tr><tr><td colSpan="1" rowSpan="1"><p>{"<GraphicsText>"}</p></td><td colSpan="1" rowSpan="1"><p>(.swf files only) If the graphic template supports dynamic text fields, you may specify the text and box number here. For an RSS News Ticker text field, enter the URL of the RSS news feed.</p></td></tr></tbody>
  </table>
</div>
