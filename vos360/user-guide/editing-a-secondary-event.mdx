---
title: Editing a secondary event
robots: noindex, nofollow
---

Note that confirmation is not required when editing or deleting secondary events.

<Tip>
  **Tip:&#x20;**&#x59;ou can edit some secondary event details directly in the **Events** table.
</Tip>

1. Click the **Edit** slider button to activate Edit mode.

2. If secondary events are collapsed, click the **Expand all secondaries** icon (![](/images/vos360/f4acbe801239313756135771.png)).

   ![](/images/vos360/d59c02ae8bfa44b9ca2cf56d.png)

3. Check the box for the secondary event you wish to edit and then click **Edit**.\
   **Result:** The **Edit secondary event** dialog opens, where you can edit the following details:

4. To delete the secondary event, click **Remove**.

5. When you have finished editing the secondary event, click **Save**.
