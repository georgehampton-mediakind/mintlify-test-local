CloudLink installation must conform to specific hardware and network requirements.

## Hardware requirements

* 4 CPU or more.

* RAM memory: 32 GB RAM or more (Max. 200 GB RAM for OVA).

* Storage: 200 GB hard disk free or more.

<Note>
  **Note:&#x20;**&#x57;hen installing CloudLink via RPM (Baremetal):

  * CentOS 7.4 (1708) minimal install
</Note>

<Note>
  **Note:&#x20;**&#x54;he CloudLink host requires AVX support. To determine if your CloudLink host CPU supports the AVX flag, or for assistance with upgrading the virtual hardware version, please contact Harmonic technical support.
</Note>
