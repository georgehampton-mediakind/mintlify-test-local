A user's role in the Harmonic Hub can be either SaaS Admin, SaaS Role, or Support Partner. Only SaaS Admins have permissions to add or delete users with a Harmonic ID and are able to grant or restrict a Harmonic ID for viewing individual tabs on Harmonic Hub.

Initially, Harmonic technical support must create a Harmonic ID for a user in your organization and assign the user role of SaaS Admin. Once a SaaS Admin exists in the Harmonic Hub, this user can create additional Harmonic IDs and designate other users as SasS Admin/SaaS Role/Support Partner if desired.

From the Harmonic ID tab, Harmonic IDs can be granted to user roles with different permissions:

* Admin role: This can grant appropriate permissions to SaaS Admin in VOS360 (Harmonic ID Administration is enabled).

* Normal role: This can grant appropriate permissions to SaaS Role in VOS360 (Harmonic ID Administration is disabled).

* Support Partner role: This can grant appropriate permissions to Support Partner (Harmonic ID Administration is disabled).
