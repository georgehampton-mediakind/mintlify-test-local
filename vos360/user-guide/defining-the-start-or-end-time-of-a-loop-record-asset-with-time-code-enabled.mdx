---
title: Defining the Start or End time of a Loop Record asset with Time Code enabled
robots: noindex, nofollow
---

1. Navigate to the **Asset Acquisition** app > **Recording&#x20;**&#x74;ab to create a loop record asset with the **Time Code** mode enabled. (Refer to the [Incoming page](/vos360/user-guide/incoming-page) for details)

2. From the **Library&#x20;**&#x74;ab, click the ![](/images/vos360/13903d3cf8257c933fa08cbd.png) icon from a time-code enabled loop record asset to open the **Clip Editor&#x20;**&#x77;indow.

   ![](/images/vos360/9a018146dba21d2643fd700d.png)

3. From the Clip Editor, use the timecode from the Loop Record asset to define the start time and end time of the recording.\
   ![](/images/vos360/6daf5cd62e765197a2516fd2.png)
