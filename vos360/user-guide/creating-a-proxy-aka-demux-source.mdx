---
title: Creating a proxy (aka demux) source
robots: noindex, nofollow
---

Proxy (aka demux) sources can be created in the Configure Broadcast app. You can descramble the supported source types.

![proxysample.png](/images/vos360/c15a41cc634573c7142693b1.png)

Under the proxy, you have a monitor feature, enabling you to see the services and components under the source.

The ![icon\_extracting.png](/images/vos360/6140b2aa518178093a80c1db.png) icon is used to extract the service from the proxy, enabling you to use it for OTT, or IPTV sources.

The ![demux\_icon.png](/images/vos360/01f343872e78e6d282770841.png)icon indicates that this is a proxy.

The ![service\_not\_extracted\_from\_proxy.png](/images/vos360/a8a984ec28c7b6b4597174b5.png) icon indicates that the service is not extracted from the proxy.

The ![service\_extracted\_from\_proxy.png](/images/vos360/b2f56cc4cf5c457588896fa5.png) icon indicates that the service is extracted from the proxy and can be used as a source for OTT or IPTV application.
