---
title: Adding unreferenced PIDs to the multiplexer
robots: noindex, nofollow
---

The Configure Broadcast app allows the ingestion of a data PID that belongs to a program without PCR or that comes as an unreferenced PID. An unreferenced PID not associated with any specific output program can be generated and re-multiplexed in a service based on remapping the input data PID to the output PID. The generated output PID is unreferenced in a service.

1. Navigate to the **Configure Broadcast** app.

2. Click the **+** button beside the **Unreferenced PIDs** output program.\
   ![](/images/vos360/f1f542c640ebe524134b1038.png)

   <Note>
     **Info:&#x20;**&#x49;f the "**+**" button is not displayed, click the ![](/images/vos360/f175f03f9e1e0581ef191b85.png) button at the top right to edit the Multiplexer settings and configure the **Unreferenced PIDs/Local Programs** checkbox.
   </Note>

3. Select the **Input&#x20;**&#x73;ource from the drop-down.

   ![](/images/vos360/90f7b0b1fd580d43fb6146da.png)

4. Specify the **Input PID** from the input source that will be remapped into the **Output PID**.

   ![](/images/vos360/c40c09048641f76209948dcf.png)

5. Verify the Unreferenced PID generated with the Output PID displayed.

   ![](/images/vos360/dd6887aff7770540ca04d483.png)
