---
title: Adding labels to a service for generating usage breakdown details in the Harmonic Hub
robots: noindex, nofollow
---

Labels can be added to a service that allow you to categorize resources and view consolidated billing by applying the same label to multiple resources. You can then download a detailed report that describes usage per label for transcoding, media processing, and egress (per live or timeshift service) from the Hub.

1. From **Channels** > **Services**, select the service you want to edit.

2. Enter a label in the **Labels** field.\
   ![](/images/vos360/e565ed557bddef70a1947dc1.png)

   <Note>
     **Note:&#x20;**&#x4C;abels are not case-sensitive and allow inputs with alphanumeric characters, dashes, and underscores. These characters are converted to lowercase letters in the Hub usage report.
   </Note>
