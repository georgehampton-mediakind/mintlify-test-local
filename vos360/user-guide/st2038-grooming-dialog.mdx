You can groom the TS input source containing the SMPTE 2038 data to perform VANC extraction and processing for your service output.

1. From the **Configure Channels** app, navigate to the **Sources** page, click **+Source**.

2. Configure the source settings in the **Inputs&#x20;**&#x70;ane.

3. Click the **Connect** button.

   <Note>
     **Info:&#x20;**&#x54;he ST2038 grooming dialog is not enabled by default. If the TS input source contains SMPTE-2038 data and is detected during grooming, the ST2038 grooming dialog will be present in a new tab. Additionally, the "ST2038 Data" type track will be visible in the Data Services grooming dialog.
   </Note>

4. From the **ST2038&#x20;**&#x74;ab, click the **+Track&#x20;**&#x62;utton.\
   ![](/images/vos360/fd16b216922f962535241fda.png)

5. For each track added, configure the Ancillary (ANC) data to be extracted from the ST-2038 source for processing.

6. Click **Ok**.
