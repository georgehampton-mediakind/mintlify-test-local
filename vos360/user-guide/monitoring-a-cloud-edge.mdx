---
title: Monitoring a Cloud Edge
robots: noindex, nofollow
---

By default, the list of Cloud Edges does not show any monitoring information. To monitor a Cloud Edge, do the following:

1. Click **Bitrate&#x20;**&#x6F;n the tile of the channel you want to monitor to activate display monitoring.

2. The Bitrate tab displays the following:

   * Packet Received.

   * Packet Lost.

   * Aggregated output bitrate graph for all output connections. The top-right corner displays the number of connections from this Cloud Edge endpoint.

3. Once your monitoring is complete, click **Bitrate** again to de-activate it. This prevents the UI from overloading.
