title: Verifying the status of a stream
robots: noindex, nofollow
---

Verify the status of a stream using the Terminal UI command.

1. From Terminal UI, press **i** to access the TUI command line.

2. From the Terminal UI command line, type `test` followed by the IP socket of the stream to be verified, then press **Enter**.

3. When you are finished, press **Enter**.
