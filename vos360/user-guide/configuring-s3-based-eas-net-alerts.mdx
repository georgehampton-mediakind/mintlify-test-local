EAS-Net is a protocol used for the distribution of Emergency Alert Systems. VOS360 can monitor an AWS S3 Bucket source to enable EAS alarms.

<Note>
  **Note:&#x20;**&#x41;fter enabling the EAS-Net option, you must restart the service.
</Note>

## Enabling EAS on your system

1. Open the **Configure Broadcast** app.

2. Click **Settings** on the top right.

3. In the EAS Mode row, select **EAS\_NET (S3 based)**.

   ![vos\_config\_eas\_setting.png](/images/vos360/b32ff86f1c6bdc7eec7e2292.png)

4. Enter your S3 bucket information in the window that appears.

   ![vos\_config\_eas\_add.png](/images/vos360/00f21417ae0d79cd46810ce4.png)

5. Click **Create**.

6. Restart the transcoding service.

<Note>
  **Note:** When **EAS\_NET** or **EAS\_NET (S3-based)** are enabled, the **Configure Channels** app allows you to configure the EAS add-on on an IPTV service. This is not applicable for services with a profile type different from IPTV.
</Note>

## Configuring the add-on to a specific transcoding service

Once the S3-based EAS-Net is set up, use the following instructions to enable it on a service.

1. Open the **Configure Broadcast** app.

2. Select the mux that contains the desired service.

   ![vos\_config\_eas\_mux.png](/images/vos360/382ab6a3b8a2c3af799308d1.png)

3. Click the pencil icon and select the **Transcoding** tab to modify the program properties.

   ![vos\_config\_eas\_toggle.png](/images/vos360/748ef75df1b703494412c2c5.png)

4. In the Add-ons section, click the pencil icon to enable the EAS-NET option.

5. Enter the Station ID related to your EAS alarm file and click **Save**.

   ![vos\_config\_eas\_addon.png](/images/vos360/ac2dffc8f966dfb1c31b30c0.png)

6. Click **Save&#x20;**&#x61;gain at the bottom of the page to enable the S3-based EAS on your service.
