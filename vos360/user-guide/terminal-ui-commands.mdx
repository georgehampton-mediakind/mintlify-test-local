Use Terminal UI commands for configuring and testing CloudLink instances.

<Note>
  **Info:** Press **i** to access the Terminal UI command line and **Esc** to cancel a command.
</Note>

Available commands:

* help = Display Terminal UI commands

* version = Verify the CloudLink version

* config network = Access and configure network connection settings

* config ntpservers = Assign Network Time Protocol (NTP) servers

* start stream = Start a test stream on the well-know multicast port 224.1.1.1

* stop stream = Stop the test stream

* test = Determine whether a stream is running on a specified IP socket
