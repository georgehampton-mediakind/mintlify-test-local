An invalid change to the transcoding profile on your VOS360 instance can prevent the benchmark system from running and cause errors and alert messages. Review the following content to avoid some common mistakes.

## Video level errors in OTT (multiscreen) benchmarks

In an OTT transcoding profile, one common problem is that the video level is incorrectly configured.

For VOS benchmarking purposes, it is permissible to set a higher video encoding level than required for production deployment. If the transcoding profile fails due to the wrong video encoding level, try using the following recommended values:

**Example**

In this benchmark example, the result indicates a failure. The failure is due to a failed input video level. The resolution, bitrate, and frame rate are indicated in the error message. By expanding the transcoding profile, the multiscreen ladder shows that the resolution 704x480 is set to AVC Level 3. The VOS server rejected the configuration. **Solution**: Update the video level to AVC level 4.2.

**Tip**: You may set all resolutions in this ladder to AVC level 4.2 in case there are other incorrect level settings.

## GOP structure errors in IPTV transcoding

In IPTV (Broadcast) Transcoding, an incorrect GOP structure setting can prevent the transcoding benchmark to run.

A typical use case is when the **Mini Gop Length M** is set too large for MPEG-2, as illustrated in the screenshot below. The error messages indicate that MPEG-2 allows no more than two B frames between reference pictures.

Valid values for **Mini Gop Length M**, or <u>gopLenM</u> in the .json file are the following:

## GOP structure errors in Multiscreen transcoding

In Multiscreen (OTT) Ttranscoding, an incorrect GOP structure setting can prevent the transcoding benchmark to run.

A typical example is the **Mini Gop Length M** configured for a given output in the ladder is incorrect. In the example below, the 3three outputs for the AVC codec baseline profile must have the **Mini Gop Length M** set to "IP" (M=1).
