---
title: Configuring a Delay Line source input
robots: noindex, nofollow
---

The source input of a Delay Line service is derived from the output of Loop Record services. The Delay Line service allows the recorded TS to be replayed with a fixed delay of XX hours/XX minutes from the input TS (without modifying the input TS).
