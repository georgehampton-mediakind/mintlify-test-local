You can create, edit, delete, and monitor cloud sources through the Cloud Sources tab in the Syndicate app.

![](/images/vos360/1bb13dd9d256a5be225309a1.png)

The tab displays the following:

* **Cloud source search bar**: Enter the name of the cloud source you want to search for.

* **Active cloud sources**: Monitor any active cloud sources.

* **Cloud source creation button**: Click the button to create a cloud source.

The following pages describe how to create, update, delete, and monitor Cloud Sources:

* [Creating a Cloud Source](/vos360/user-guide/creating-a-cloud-source)

* [Updating a Cloud Source](/vos360/user-guide/updating-a-cloud-source)

* [Deleting a Cloud Source](/vos360/user-guide/deleting-a-cloud-source)

* [Monitoring a Cloud Source](/vos360/user-guide/monitoring-a-cloud-source)
