---
title: Configuring the output of the mux service
robots: noindex, nofollow
---

1. From the **Configure Channels** app, select the **Destinations** tab.

2. &#x20;Locate or create the MPTS destination profile for your mux service and select it.

3. Click **+Output** and select **SRT**.

4. In the **IP Address** field, paste the LRS ingress URL you copied in [Creating the output from a cloud source (LRS ingress)](/vos360/user-guide/creating-the-output-from-a-cloud-source-lrs-ingress).

   <Note>
     **Note:&#x20;**&#x4D;ake sure that you select the correct MPTS destination profile when you create the mux service.
   </Note>

5. Click **Create**.
