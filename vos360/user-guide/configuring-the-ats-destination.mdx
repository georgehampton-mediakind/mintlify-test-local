**Before you begin**\
[Configuring a source input](/vos360/user-guide/configuring-a-source-input)

Configure the ATS destination to use an ATS profile and multicast IP address.

1. From the **Configure Channels** app, navigate to the **Destinations** page, click **+ Destination**.\
   ![](/images/vos360/48b93041cfa4dbc665cac409.png)

2. For **Destination Name**, type the name of the ATS destination.

3. For **Type**, select **ATS**.\
   The default output type changes to CloudLink.

4. Verify that the selected **Profile** is an ATS profile.

5. Optionally, in the **Labels** field, enter a label associated with the destination, such as Cartoon or Premium.

   <Note>
     **Info:&#x20;**&#x4C;abels can help you search and find destinations more quickly.
   </Note>

6. f you wish to use an output that is different from the default, click **Remove output** and then click **+Output** and select the desired output type from the list.\
   ATS destinations use IP, CloudLink, and HSP outputs.

7. (Optional) In addition to the Primary destination output, you can create additional outputs for the same destination type (e.g. 2nd IP, 3rd IP and so on) by clicking **+Output**.

   ![vos360\_outputs\_ats.png](/images/vos360/b2bebcd64d90a1004f53a977.png)

9. For ATS output with **CloudLink** destination, select the name of the downlink CloudLink.

10. For ATS output with **HSP&#x20;**&#x64;estination, no custom configuration is required.

11. For ATS output with **Cloud (Live** **Routing)** destination, the Cloud channel will be available as a source to be up-linked to Harmonic's Cloud via Live Routing Service. This configuration applies to **VOS360** and needs to have access to the Syndicate app only.

12. For ATS output with **SRT** destination, use the default SRT settings or configure the custom SRT settings:
