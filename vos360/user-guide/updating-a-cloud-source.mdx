robots: noindex, nofollow
---

To update a Cloud Source, do the following:

1. Navigate to the **Syndicate&#x20;**&#x61;pp.

2. From the Cloud Sources tab, click ![](/images/vos360/c5178820e3ab4a6ff77d5de6.png) on the tile of the channel you want to update.\
   The Edit window appears.

3. Update the following information:

   * Cloud Source name.

   * Status (choose from **Online&#x20;**&#x6F;r **Offline**).

4. Choose from the following options:

   * **Save**: Save your changes.

   * **Revert**: Revert any changes.

   * **Close**: Take no action.
