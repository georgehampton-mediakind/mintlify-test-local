title: Removing unwanted content from assets
robots: noindex, nofollow
---

You can remove unwanted content by using multi-cutting and stitching in the Clip Editor for your VOD/AOD assets.

1. Navigate to the **Asset Acquisition** app. Select the **Library&#x20;**&#x74;ab and click the ![](/images/vos360/13903d3cf8257c933fa08cbd.png) icon from a compatible asset to open the **Clip Editor&#x20;**&#x77;indow.

2. Add and define one or more segments using the Segment Editor.\
   ![](/images/vos360/629996bea6670a4da21d78cd.png)

3. When the segments are correctly defined, click on the **Extract&#x20;**&#x62;utton. A window will open as follows:

   ![](/images/vos360/c87f2ced011c7135200568cc.png)

4. Set the name for your new asset in the input "Asset name".

5. Select the transcoding profile from the drop-down menu (only *e\_Multiscreen* profiles).

6. Click on the **Extract** button to create a new asset from the defined segments.

7. If the extraction is successful, an information pop-up will be displayed.

8. Click on the **Close&#x20;**&#x62;utton to return to the Clip Editor window.

   ![](/images/vos360/bae1e3a6ef20016a02e34986.png)

9. Close the Clip Editor window once the extraction is done.

10. The newly created assets will be displayed in the Library tab once the job is finished
