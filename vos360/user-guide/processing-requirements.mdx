Harmonic follows a process that defines the CPU and memory needed for a transcoding profile. This process is called benchmarking and needs a transcoding and destination profile to be calculated.

To modify your profiles, do the following:

<Note>
  **Note:&#x20;**&#x56;erify that Harmonic has enabled the option to allow you to modify profiles through the Hub.
</Note>

1. Log in to Hub.

2. Select the **Software** tab.

3. Open an IPTV or OTT transcoding/destination profile (e.g."Multiscreens Gold HD v.1"), and make the desired video and audio configurations. Make sure to follow the [Lab Wizard profile guidelines](/vos360/user-guide/lab-wizard-profile-guidelines).

4. Click the **Processing Requirements** section under a transcoding profile and enter the information required for calculating CPU/Memory processing data through a benchmark. Make sure that you select the correct destination profile in **Destination Profile**.

   ![](/images/vos360/22824727a4d0963f8c95744b.png)

5. Add text in the **Save with a message...** field to distinguish your new version.

6. Click **Save as version** to create a new profile version, and wait for the benchmark process to finish. Depending on the complexity of the profile, this process can be immediate or can take up to 2 hours.

7. Use the profile if the status is **Ready for Provision**.

Other benchmark-related fields are hard-coded according to the transcoding profile type (IPTV/OTT), or are read from the selected destination profile. They are not required from the Profile Editor UI.

## Benchmarking results

After you finish entering the processing requirements, the new profile triggers the benchmark process. A record is automatically created using the provided inputs in the Profile Editor and other defaults.

As the benchmark process calculates the CPU/memory requirement, it displays the following status updates:

* Calculating requirements

* Successful completion

* Unsuccessful completion

### Calculating requirements

![](/images/vos360/5c63d751c0f81f48313a7dc1.png)

At this stage, **No (calculating CPU/memory requirement data...)** is displayed under the **Ready for Provision** field. The profile is not available and cannot be used.

### Successful completion

![](/images/vos360/8f91a29d62d3d909149a3a29.png)

At this stage, **Yes** is displayed under the **Ready for Provision** field. The profile is ready for use.

### Unsuccessful completion

![](/images/vos360/dbc1198ddb4e17ef3ce86833.png)

At this stage, No (**Please contact Harmonic support)** is displayed under the **Ready for Provision** field. The profile cannot be used. Contact Harmonic Support through the Hub support process. Make sure to provide your profile name and ID.
