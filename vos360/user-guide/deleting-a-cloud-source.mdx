title: Deleting a Cloud Source
robots: noindex, nofollow
---

<Warning>
  **Warning!**

  Deleting a Cloud Source also automatically deletes any connected Cloud Edges.
</Warning>

1. Navigate to the **Syndicate&#x20;**&#x61;pp.

2. From the Cloud Sources tab, click ![](/images/vos360/c5178820e3ab4a6ff77d5de6.png) on the tile of the channel you want to delete.\
   The Edit window appears.

3. Click **Delete**.\
   A confirmation window appears.

4. Click **Confirm**.
