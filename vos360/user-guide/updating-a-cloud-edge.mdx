To update a Cloud Edge, do the following:

1. From the Cloud Edge tab, click ![](/images/vos360/c5178820e3ab4a6ff77d5de6.png) on the tile of the channel you want to update.\
   The Edit window appears.

2. Update the following information:

   * Cloud Edge name.

   * Status (choose from **Online&#x20;**&#x6F;r **Offline**).

3. Choose from the following options:

   * **Save**: Save your changes.

   * **Revert**: Revert any changes.

   * **Close**: Take no action.
