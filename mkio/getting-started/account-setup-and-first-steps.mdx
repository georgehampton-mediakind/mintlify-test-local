Activate a marketplace or direct-sales subscription before you create media resources. After activation, sign in to MK.IO and create a project for your workflows.

## Choose a subscription path

MK.IO supports Azure Marketplace, Amazon Web Services (AWS) Marketplace, and direct-sales payment methods. Use the path that matches your agreement with MediaKind.

Marketplace subscriptions have no upfront activation cost. Billing begins when you use chargeable MK.IO services.

### Azure Marketplace

1. Open MK.IO in Azure Marketplace and select **Get it now**.
2. Complete your profile information and allow Microsoft to share the required account information with MediaKind.
3. Configure the subscription:
   * Select the MK.IO plan and choose **Subscribe**.
   * Select an Azure subscription and resource group.
   * Enter a name for the MK.IO subscription under **SaaS details**.
   * Select **Review + subscribe** and review the terms.
4. Confirm your contact details and select **Subscribe**.
5. When **Configure your account** becomes available, select it to complete activation in MK.IO.

If MediaKind issued a private offer, follow [Accept an Azure Marketplace private offer](/mkio/how-to/managing-your-organization/accept-an-azure-marketplace-private-offer).

<Warning>
  Keep marketplace auto-renewal enabled if the MK.IO subscription should remain active beyond its current term.
</Warning>

### AWS Marketplace

Use [Subscribe through AWS Marketplace](/mkio/how-to/managing-your-organization/subscribe-through-aws-marketplace) to purchase the subscription, activate it in MK.IO, and create an AWS-based project.

### Direct sales

If your organization has a direct agreement with MediaKind, use the redemption link provided for that agreement. Direct agreements can include volume pricing and professional services.

1. Open the redemption link and sign in to MK.IO.
2. If you do not have an account, select **Create an account** and use Microsoft authentication or email.
3. Enter the requested organization details when creating an email-based account.
4. Review the terms and redeem the purchase.
5. Create a project and select the required cloud region.

If you belong to more than one organization, select the intended organization before redeeming the purchase.

## Sign in to MK.IO

1. Go to [mk.io](https://mk.io) and select **Sign in**.
2. Use the authentication method associated with your account.
3. Select an organization and project in the portal.

See [Navigate the MK.IO portal](/mkio/getting-started/platform-navigation-and-key-features) for a map of the portal areas and their documentation.

## Create a project

A project contains the media resources for a workflow. Each project uses a selected cloud provider and region.

Creating a project does not incur a charge. You cannot change the project's cloud provider or region after creation, so confirm both selections before you continue.

1. Open [Projects Overview](https://app.mk.io/settings/overview/projects).
2. Select **Create new**.
3. Select the cloud provider, region, project name, and payment method.
4. Select **Create**.

After creating the project, [connect cloud storage](/mkio/getting-started/connect-cloud-storage). You can manage project access from [Access Management](https://app.mk.io/settings/accessManagement/teams).
