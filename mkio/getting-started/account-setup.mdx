Before you can upload assets, run transcode jobs, or start a live stream, you need an MK.IO account with at least one project and connected cloud storage. This guide walks you through the initial setup so you are ready to start a workflow immediately after.

## Organization and project structure

Every MK.IO account belongs to an **organization**. An organization is the top-level container for billing, user management, and API tokens. Within an organization you create one or more **projects**. A project holds all the media resources for a single product, team, or environment — storage accounts, assets, transforms, live events, and streaming endpoints all live inside a project.

Most teams create separate projects for production and non-production workloads so that staging and testing activity never touches live infrastructure.

## Set up your account

<Steps>
  <Step title="Create your account">
    Go to [app.mk.io](https://app.mk.io) and sign up for an account. After you verify your email address, you are taken directly into the MK.IO portal.
  </Step>

  <Step title="Create or join an organization">
    When you sign in for the first time, MK.IO prompts you to create a new organization or accept an invitation to an existing one. If you received an invitation by email, click the link in that email rather than creating a new organization.

    Give your organization a descriptive name — it appears in API responses and billing records.
  </Step>

  <Step title="Create your first project">
    Inside your organization, go to **Projects** and click **Create Project**. Give the project a name (for example, `production` or `my-first-project`) and select the region closest to your users and storage.

    <Note>The project region affects latency for streaming endpoints and data transfer costs for connected storage. Choose the region closest to where your audience and storage buckets are located.</Note>
  </Step>

  <Step title="Connect cloud storage">
    MK.IO uses your own cloud storage to hold media files. Before you can upload or process assets, connect at least one storage account. Go to **Storage** in the left navigation and follow the prompts for Amazon S3 or Azure Blob Storage.

    See [Connect cloud storage](/mkio/getting-started/connect-cloud-storage) for full configuration steps including IAM policy setup and SAS token generation.
  </Step>

  <Step title="Create an API token">
    If you plan to use the MK.IO REST API, create a personal API token:

    1. Click your email address in the top-right profile menu.
    2. Navigate to **Your personal API tokens**.
    3. Click **Add Token**, enter a description and expiration date (UTC), then click **Create**.
    4. Copy the token immediately — it is only visible for five minutes after creation.

    Use this token as the `Authorization: Bearer <token>` header on all API requests to `https://app.mk.io`.

    <Warning>Store your API token securely. If you lose the token before copying it, revoke it and create a new one. Never commit tokens to source control.</Warning>
  </Step>

  <Step title="Invite team members (optional)">
    Go to **Organization Settings** > **Users** to invite colleagues. Assign roles based on the access each person needs — admin, editor, or viewer. Users you invite receive an email with a link to join your organization.
  </Step>
</Steps>
