MK.IO meters usage for media processing and delivery resources. Rates can change, so use the current pricing table instead of relying on figures copied into workflow guides.

Review the [MK.IO pricing table](https://mediakind.com/mkio/pricing/) for current rates and calculation methods. Cloud-provider storage, networking, and egress charges are billed separately through the provider.

## Actions and usage

The following actions do not generate MK.IO usage charges by themselves:

* Signing up and creating a subscription.
* Connecting storage and importing assets.
* Creating a streaming endpoint while leaving it stopped.
* Creating streaming locators.
* Using and integrating MKPlayer.

Usage charges apply when you run services or process and deliver content. Chargeable activity includes running streaming endpoints, live passthrough or encoding events, VOD transcoding, and network delivery. Check the current pricing table before estimating a workload.

Use [Billing and usage](/mkio/how-to/managing-your-organization/billing) to review usage by project and manage payment methods for an organization.
