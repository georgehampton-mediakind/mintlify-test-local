Access a registered device's local web interface through MK.IO when you cannot connect to its local network. MK.IO proxies the interface over a secure tunnel.

1. Open the project that contains the device, then go to **Devices**.
2. Select the device.
3. In the top-right corner of the properties panel, select **Access remote UI**.

Log in to the device interface and use it as you would on the local network.

The following functionality is not available through the remote UI:

* Downloading a support package from **Servers**. Use [Collect device logs](/mkio/how-to/managing-edge-devices/support-packages) in MK.IO instead. MK.IO generates the package and emails you a download link.
* Uploading a software bundle from **Appliance**.

You can perform these actions by accessing the unit directly on a connected network.
