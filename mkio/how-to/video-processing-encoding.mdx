The **Video Processing** area of the MK.IO portal contains Transforms and Jobs. A transform defines reusable processing, while a job applies that transform to an input asset and writes the result to an output asset.

* [Compare encoding transform presets](/mkio/reference/encoding-transform-presets/encoding-transform).
* [Configure asset conversion transforms](/mkio/reference/encoding-transform-presets/asset-conversion-transform).
* [Understand transforms and jobs](/mkio/understanding/core-concepts/transforms-and-jobs).

## Jobs

* [Run VOD processing jobs](/mkio/how-to/video-processing-encoding/run-vod-transcode-jobs).

## AI workflows

AI workflows are configured as transforms and run as jobs. Use the [AI workflows guides](/mkio/how-to/ai-features) for transcription, translation, and VOD dubbing tasks.
