MKPlayer is an HTML5 video player SDK used for playing back HLS and DASH adaptive bitrate streams without using browser plugins.

![7302df2 mkplayer sdk](/images/mkio-player-sdk.png)

## MKPlayer SDK

This comprehensive guide to the MKPlayer SDK will help you navigate the features and functionalities of our powerful streaming video player. MediaKind created this guide for developers and MK.IO users to help you make the most of the MKPlayer for importing assets from your cloud storage and/or integrating our player into your application.

You can find our NPM library at [https://www.npmjs.com/package/@mediakind/mkplayer](https://www.npmjs.com/package/@mediakind/mkplayer).

Start with [Install and initialize MKPlayer](/mkio/reference/player-sdk/setup).
