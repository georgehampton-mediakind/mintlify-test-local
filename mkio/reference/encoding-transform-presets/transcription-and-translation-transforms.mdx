MK.IO offers AI-powered VOD transcription and VOD translation features that allow you to generate subtitles from audio tracks. The generated subtitles are delivered in WebVTT format into an output asset and can be subsequently added to the manifest of the asset with a [track insertion transform](/mkio/reference/encoding-transform-presets/add-a-track-to-a-vod-asset).

<Info>
  On-demand transcription and translation are only available for MP4 assets.
</Info>

## VOD transcription

MK.IO provides a built-in preset, **Predefined\_ACSVodTranscription,** to be used in such AI workflow transform for VOD Transcription. When selecting this VOD transcription preset, all you need to do is specify the original language of the audio track using the BCP-47 format.

It is also possible to provide a list of words or phrases that are expected in the audio feed in order to improve their recognition.

A full list of supported languages is available below:

## VOD translation

MK.IO also provides a built-in preset, **Predefined\_ACSVodTranslation,** to be used in such AI workflow transform for VOD translation. When selecting this VOD translation preset, you need to specify the original language of the audio track using the BCP-47 format. You also need to specify a list of languages to which you want the subtitles to be translated.

It is also possible to provide a list of words or phrases that are expected in the audio feed in order to improve their recognition.
