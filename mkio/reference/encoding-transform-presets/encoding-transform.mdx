## Constant video quality presets

The presets with `CVQ` in their name use Constant Video Quality (CVQ). These presets adjust the bitrate and encoding parameters to maintain consistent visual quality across the input content.

Use a standard preset for content shorter than 30 seconds. For content longer than 60 seconds, the CVQ presets can reduce the output bitrate by 15 to 30 percent without a perceptible change in visual quality. Older Windows CE and Roku clients may not be compatible with CVQ output.

CVQ presets use the Advanced encoding tier. See [MK.IO pricing](https://mediakind.com/mkio/pricing/) for current rates.

## Output file format

MK.IO uses the MP4 format for Video on Demand (VOD) assets. An asset generated through VOD transcoding contains the following files:

* MP4 files (`.mp4`), one per video rendition with all audio streams interleaved.
* A server manifest (`.ism`) used as the access point for streaming endpoints.
* A client manifest (`.mpd`).
* Index files (`.mpi`), one per rendition, used to improve streaming-delivery performance.

VOD transcoding uses the input filename as the prefix for all output files in the asset.

Existing assets that use the earlier Smooth Streaming or MP4 layout remain deliverable through MK.IO streaming endpoints. Use an [asset conversion transform](/mkio/reference/encoding-transform-presets/asset-conversion-transform) when a newer workflow requires the current MP4v4 layout.
