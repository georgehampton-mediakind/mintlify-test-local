MK.IO video processing turns source files into streaming-ready content. The system is built around two resources: **transforms** define what processing to apply, and **jobs** execute that processing on a specific input. Outputs land in your connected cloud storage as new assets ready for publishing.

## How VOD processing works

The processing pipeline separates configuration from execution. You define a transform once and run it against many inputs without repeating the configuration each time.

<CardGroup cols={3}>
  <Card title="Transform" icon="gear">

  </Card>
  <Card title="Job" icon="play">

  <Card title="Asset" icon="film">

## Transform types

MK.IO supports several categories of transform, each suited to different output requirements.

| Transform type | What it produces |
| --- | --- |
| **Encoding** | Adaptive bitrate video renditions in H.264 or H.265 |
| **Thumbnail** | JPEG images at specified intervals or percentages |
| **Asset conversion** | Converts legacy formats (such as HSS) to current MP4 layout |
| **Track insertion** | Adds audio or subtitle tracks to an existing encoded asset |
| **AI pipeline** | AI-generated outputs such as transcription, translation, or dubbing |

## Predefined presets

MK.IO ships with a library of predefined presets so you can start processing without building a custom configuration. Common presets include:

- `H264MultipleBitrate1080p` — adaptive H.264 ladder up to 1080p
- `H264MultipleBitrate720p` — adaptive H.264 ladder up to 720p
- `H264MultipleBitrateSDWithCVQ` — SD ladder with Constant Video Quality
- `Predefined_ACSVodSpeechToSpeech` — AI dubbing pipeline

You can also define fully custom encoding transforms with per-layer codec and bitrate settings.

## Input formats

The encoding transform accepts a wide range of source formats:

- **Video containers**: MP4, MKV, MOV, AVI, WebM, ISMV, WMV, and more
- **Video codecs**: H.264, H.265, AV1, VP8, VP9, H.263, MJPEG, MPEG-1, VC-1, Sorenson Spark
- **Audio codecs**: AAC, MP3, Opus, Vorbis, ALAC, ADPCM, DPCM
- **Frame rates**: Variable frame rate sources are supported

## Job priority

When you submit a job, you choose a priority level that affects queue ordering.

| Priority | Behavior |
| --- | --- |
| **High** | Picked up next when a processing slot is free. Does not interrupt running jobs. |
| **Normal** | Standard queue position. Default for most workflows. |
| **Low** | Yields to Normal and High jobs. Best for background processing. |

## Job states

A job moves through a defined state machine from submission to completion.

`queued → scheduled → processing → finished`

If a problem occurs, the job enters an `error` state with a description of what went wrong. You can cancel a queued or scheduled job, but not one that is already processing.

## AI workflows

MK.IO supports AI-powered processing alongside standard encoding. Available AI pipelines include:

- **VOD transcription**: Generates WebVTT subtitle tracks from audio
- **VOD translation**: Transcribes audio and translates to up to 25 languages
- **VOD audio dubbing**: Generates full dubbed audio tracks in target languages
- **Live transcription**: Real-time subtitle generation during a live event

See [AI Dubbing](/mkio/vod/ai-dubbing) for a complete dubbing workflow.
